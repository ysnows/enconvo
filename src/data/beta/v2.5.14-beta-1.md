# Enconvo 2.5.14 Beta 1

Thanks for testing Enconvo 2.5.14 Beta 1. This build adds Temporary chat for one-off questions, lets Dictation pause and mute you in your meeting while you dictate, lets you press Return to dictate and send in one go, moves the Live Captioning bar where you want it, takes a remote computer's Screen to real full screen, clears a chat's notifications on your other devices once you read it, and brings many fixes to the Windows and Linux apps.

- Claude Code chats: an Ultracode switch in the effort picker, shown while Claude Code says the session can use it (CLI 2.1.322 or later, with workflows on and a model that supports it). It turns on workflow orchestration for the rest of the session at whatever effort is picked, keeps it across an effort change, and follows a typed `/effort ultracode`.
- Recordings and Live Captioning: a long recording transcribes with Enconvo Cloud Fast again. A file over 95 MB (about an hour as the WAV a Recording saves, or a long video) was refused with HTTP 413 before the upload began; it is now re-encoded as compact speech audio first, so recordings up to the 300-minute limit go through. Reported by plkv_andrii.
- Fixed Claude Code's Ultracode switch showing an old state after effort or model changes, a session reopening, or a failed change, and translated it in all ten interface languages.
- Fixed large Recordings and Live Captioning recordings failing with HTTP 413 in Enconvo Cloud Fast, including stopping audio preparation when transcription is cancelled.
- Chat composer: an attached video shows its first frame with a play mark instead of a plain video icon, and falls back to the icon when the frame can't load.
- iPhone: an x.com link opened in a chat's side panel shows the post instead of a blank page. X sent the app's web view to Safari with an `x-safari-https:` redirect that the page tab quietly dropped; the tab now reports itself as Safari, as the Mac's side panel does, and opens any such redirect in place.
- Dictation: a Live transcript switch hides the words while you dictate, so the bar keeps just its buttons and waveform and covers less of the screen. Turn it on or off in the card that opens when you hover over the bar, without stopping the dictation, or in Settings › Dictation › Listen. Notes, the wait for a microphone, and Clean up's Insert as Spoken still show. Requested by plkv_andrii.
- Chat history is the same everywhere: the Dynamic Island's History and the Smart Bar's chat list no longer show AI Command chats (Translate, Fix Spelling and Grammar, your own AI Commands), which the Chat Window never listed, so a chat deleted there no longer lingers in the other lists. The App Sidebar's history now lists only the chats started in that app's sidebar, and the Dock badge counts the same chats as the lists. Reported by Vitaliy Malanchuk.
- Fixed Project chats loading only the first 32,000 characters of the project's AGENTS.md or CLAUDE.md: the agent now gets every instruction file from the repository root down to the working folder in full, so rules near the end of a long file are no longer missed.
- Dictation: press Return while you dictate, holding the hotkey or after tapping it, and the dictation stops, its text goes in and is sent, in one press. Stopping with the hotkey or ✓ only inserts, as before. The setting, now Settings › Dictation › Insert › Return inserts and sends, is on by default; an app rule's Return key column still turns it on or off for one app. Fixed the Return never sending in Discord, Edge, Chrome, Slack and other Chromium or Electron apps, which ignored the key the way it was sent. Requested by plkv_andrii.
- Live Captioning: choose where the captions bar opens: Left Side (as before), Right Side, Top Center or Bottom Center, where captions line up at the bottom like subtitles. With more than one display, also choose its screen, or keep the one with the pointer. Pick both in the Start Live Captioning window, or right-click the captions bar to move it during a session. Requested by plkv_andrii.
- Added `agent/session/list`, a route that lists the chats running now across every agent and Project (Claude Code and Codex chats included), with each one's title, agent and Project; it checks each run, so a chat whose status still says running after a crash is left out, and `filter: "waiting"` lists the chats waiting for your answer. `agent/session/status` now checks one chat only and asks for its `sessionId`.
- Added `agent/session/steer`, a route that adds a message to the turn another chat is running now without stopping it, as `agent/session/list` finds them; a chat that isn't running answers `not_running` and points to `agent/call`, and a run below Full access can't steer an Enconvo turn.
- Added Temporary chat for one-off questions: turn on the dashed-bubble switch on a new chat in the Chat Window, the App Sidebar or the Dynamic Island, and that chat stays out of your chat history, saves no Memories, and is deleted when you leave it. Keep chat on its banner saves it as a normal chat instead. Requested by Vit_MK.
- A computer's Screen can now go real full screen: the new full screen button (or ⌃⌥F) puts the picture over the whole display, with the controls sliding in when the pointer reaches the top edge; Esc also leaves it while watching. A Fill switch next to it scales the picture to fill the view with no black bars, cropping the edges that do not fit.
- Dictation can pause: point at the level in the Dictation HUD and click Pause, or press ⌥P (change it in Settings › Dictation › Pause / Resume). The microphone goes off and your words stay; Resume, or the same key, goes on with the same dictation, and the Dictation hotkey or ✓ finishes it. The key works only while you dictate, and a dictation you hold a key for has no pause.
- Dictation mutes you in your meeting while you dictate: in a Zoom, Microsoft Teams or Google Meet call, starting a dictation mutes your microphone there, and finishing or pausing it unmutes you. A call you had muted yourself stays muted. Turn it off in Settings › Dictation › Mute my meeting microphone while dictating.
- Changed the Dictation Draft panel to say less: its header shows only Draft and, at its end, the app the draft works in; esc and the Dictation key stand alone without a word beside them; and the Dictation HUD below no longer repeats Draft. ↵ now always pastes the draft into the app it started in, bringing that app back first when another one is in front, instead of copying it.
- Windows and Linux: routes of macOS-only extensions (Apple Calendar, Notes, Reminders, Contacts, Mail, Maps, Messages, Music, PopClip, File Search) now answer at once with which systems they work on (status 501), except a command in them that names that system itself, and so do routes whose Python part doesn't run there (Local Models). Before, they failed with a bare server error (`spawn osascript ENOENT`) that told an Agent nothing.
- Windows server (`enconvo --headless`): reading a web page no longer waits 30 s on every fetch for a browser to start. Enconvo starts your browser for it only when one has had the Enconvo Companion extension connected before, and after a start that didn't connect it reads pages without a browser for 5 minutes, so only the first fetch waits. Before, each fetch waited 30 s.
- The Out of Cloud points card (and its Waiting and Points added states) now shows in your interface language. Before, every one of its words stayed English in all 10 languages, as seen on a Chinese Windows.
- Windows: a Snippets keyword now expands in a Notepad tab opened with Ctrl+N, and wherever Enconvo's record of the last app is another window of the app in front. Before, the keyword stayed as typed and nothing was pasted.
- Windows: the Desktop Pet and the Avatar now stand on your desktop with nothing around them. Before, each sat on an opaque light-grey square (dark grey in dark mode) the size of its window area.
- Windows: an Agent can now close its own desktop Avatar (`agent/avatar/hide`), as on the Mac. Before, the call failed with "not supported on win32".
- Windows: a side panel page tab on a site that redirects to another site before refusing to be shown in other pages (bing.com goes on to cn.bing.com) now says it can't be shown there and offers to open it in your browser. Before, the tab stayed blank.
- Windows: when an Agent opens a web page beside a chat that was last shown in the Dynamic Island, and the island is folded, the page now opens where you can see it instead of in the folded island. Before, the page went to the folded island and the Agent was told the site might refuse to be shown.
- Windows: opening the Smart Bar no longer fails twice while its recommended prompts load. Before, each failure skipped the rest of that update (the placeholder, the pin, stop and send buttons, the actions and the model picker), and no spinner showed while the prompts loaded.
- Windows: docs now export to PDF, their widgets draw as pictures, and WebP, AVIF and SVG pictures make it into Word exports, using the Microsoft Edge every Windows PC has (or Chrome). Before, PDF export said "PDF is printed by the Mac app" and those pictures were left out.
- Windows and Linux: designs, decks and dashboards now export to PDF and PNG, single elements export as PNG or JPEG, film stills and canvas previews draw, and deck, dashboard and film checks measure the page, all with the installed Microsoft Edge (or Chrome, Chromium). Before, each said it is drawn by the Mac app.
- Changed Browser Use so the tabs an Agent opens close when its turn ends, as Computer Use puts apps back: a page the Agent hands you as the result, a tab handed to you, a tab you pinned and the tab you are looking at stay open, and your own tabs are never closed. Before, every task left its tabs open in a tab group of their own.
- Added read sync for notifications: once you read a finished chat on your Mac, iPhone, or Android phone, its notification disappears from your other devices, while a question that still waits for an answer stays.
- Added Send selected text to Settings > Dictation > Draft, on by default: when you start a Draft with text selected that cannot be edited, such as a message or part of a web page, the model gets it as reference and the draft is new text that Return pastes into the field you go back to, instead of a rewrite that could only be copied. Selections on Safari and other web pages are now read as well.
- Fixed a message sent from the Smart Bar sometimes going nowhere, leaving the Smart Bar on Responding… and a chat with only a title and no messages in the main window. When a chat on the same page closed, it took the Smart Bar's send event with it; now a chat gives up only the events it still holds, and the chat still on screen takes them back. If a send still isn't picked up, the Smart Bar sends it once more, and if that fails it shows an error and puts your message back in the input.
- Changed Android notifications for Mac activity, chat replies and messages so sound, vibration, the notification light and the app badge are all on by default, also on phones that already had Enconvo installed.
- Dictation also mutes you in an Enconvo Conference and in Zoom and Microsoft Teams calls that run in a browser tab while you dictate, and unmutes you when you finish or pause, as it does for the Zoom and Teams apps and Google Meet.
