# Enconvo 2.5.14 Beta 2

Thanks for testing Enconvo 2.5.14 Beta 2. This build brings richer recording summaries with templates and an output language, recommends a model for each kind of work, adds an Active group that gathers the chats that need you, lets you message a running task, and makes Dictation and Live Captioning more flexible.

## Highlights

- **Recording summaries with templates**: Meeting summary, Lecture notes, Interview highlights or your own, written in the language you pick, with timelines, tables and checklists.
- **Model recommendations**: model pickers and New Agent suggest the best fit, the lowest-cost and the best-quality model for the job.
- **Active chats on top**: the Chat Window, iPhone and Android sidebars gather the chats that are running, waiting for you or have a new result.
- **Talk to a running task**: type while the agent works and Send adds your message to the task; an unrelated request goes to a subagent.
- **Tutorials in Settings**: update videos and walkthroughs play inside Enconvo.

## Recordings

- Added an output language to recordings: pick the language a recording's summary, action items and template results are written in from the top of its side panel, or set one for all new recordings; the transcript and your own notes stay as they are.
- Added summary templates to recordings: besides the Meeting summary there are Lecture notes and Interview highlights, and you can write your own in plain words, try it on a recording before saving, and switch a recording between templates while each result is kept.
- Changed recording summaries to show more than text: the Meeting summary has figures and a timeline whose times jump to that moment, and a template's result can use cards, tables, checklists, flashcards, quizzes and charts.
- Added Show translation to a recording's Notes tab: it adds a translation in the recording's output language under each note you typed, and your notes stay as you wrote them.
- Added Send tasks to Action items to summary templates, so the tasks a template finds also show in the recording's Action items tab, where you can tick them off.
- Added Talk time to the Meeting summary, showing each speaker's share of the conversation when a recording has two or more speakers.
- Added Summary settings to the Recordings page, next to New recording, for the output language and template new recordings take and for managing your templates.

## Chats and Agents

- Changed the composer button while a task runs: once you type or attach something it turns from Stop back into Send, and a click sends the message into the running task as Return does (hold ⌘, or Ctrl on Windows and Linux, to queue it instead).
- Changed a message you send while the agent is working: an unrelated request now goes to a subagent that works in the background while the agent carries on with its task, instead of waiting for the task to finish.
- Changed a Project's main chat so its agent can start subagents for its own work, alongside the tasks it gives to the Project's members.
- Added an Active group at the top of the Chat Window sidebar that gathers every chat that is running, waiting for you, failed or has a result you haven't opened, with its Project and state, so none has to be looked for down the lists.
- Design work in a Project now starts from the project's own DESIGN.md: when the agent loads its design skill, the whole file comes with it, so its colours, type and component rules shape the design from the first artboard.
- Changed how an answered question shows in a chat: each answer is now a quiet capsule beside the question, several chosen options sit one per line under it with what you typed, a call that asked several questions names each, and a skipped question shows a dashed Skipped capsule, instead of everything joined on one cut-off line.
- Added a Wrap Code setting (Settings › General › Appearance) and a wrap button beside Copy on code blocks in a reply, so long lines of code can wrap instead of scrolling sideways; it is off by default. Requested by liduchuan.
- Changed the buttons on a code block in a reply to plain icon buttons on the block itself, without the dark box that showed behind them in the Chat Window.
- Fixed Temporary chat in the Dynamic Island and the App Sidebar: turning it on now lights the switch blue and gives the composer a dashed edge with a Temporary chat tag you can close, and a chat you start there really stays out of your history and is deleted when you leave it.
- Fixed some cases where a message sent from the Smart Bar, for example to Claude Code, failed with "Couldn't send the message": the Smart Bar now hands it to its own chat page more reliably, and when it still can't, your text, attachments and the message you were editing all come back to the input.
- Added a voice button to the PopBar Ask panel: click it or press the Voice Command hotkey to speak your ask, and it is sent when you stop.

## Models

- Added model recommendations to model pickers in Settings: the list now starts with the best fit, the lowest-cost and the best-quality model for that kind of work, each with a short reason and its price, and a line under the setting tells you when the chosen model costs many times more than the recommended one.
- Added a recommended model to New Agent: it reads what the agent will do from its description and suggests a model, with a cheaper and a stronger one beside it, that you can pick in one click.
- Changed the Enconvo Cloud Plan model list to group models by vendor in every model picker, the Smart Bar and other native windows included: Enconvo's own models come first, then Anthropic, OpenAI, Google and the rest, each under its name with a count. A vendor shows its newest four models and "Show N earlier models" opens the others; the chat's model always shows, and a search still lists every match.
- Added a Generate tab to an agent's avatar, in Create New Agent and in the agent's settings: it draws four avatars from the agent's name and description in the style you pick (Flat, 3D, Anime, Photo, Line or Watercolor) with your image model, only when you press Generate, and you can add details or draw again before choosing one. Requested by Vit_MK.

## Dictation and Live Captioning

- Fixed Return inserts and sends leaving the dictated text unsent in web apps and other slow editors: Enconvo now waits until the pasted text shows in the field before it presses Return.
- Fixed Return inserts and sends in the Chat Window: dictating into the composer with the Dictation key and pressing Return now sends the message instead of leaving the text in the box.
- Added a Return inserts and sends switch to the Dictation HUD card, under Draft, so you can turn it on or off while you dictate.
- Added a Send after inserting switch in Settings › Dictation › Insert: when a dictation ends, its text is inserted and sent without pressing Return. It is off by default and works beside Return inserts and sends.
- Changed the Dictation Pause / Resume hotkey to take more than a key combination: a single key such as Space, or one modifier key on its own that you tap, double-tap or hold (holding pauses until you let go). Set it in Settings › Dictation › Pause / Resume.
- Changed the Dictation window to leave out the LISTENING label while you simply dictate, so it takes less room; Paused, Clean up's progress and a failure still show their label.
- Fixed Dictation not muting you in a Google Meet, Zoom or Teams call that runs in Safari or in a website added to the Dock from Safari.
- Fixed Live Captioning not moving to another display when one was picked in the captions bar's right-click menu: the bar was pulled back to the edge of the display it was on. Reported by plkv_andrii.
- Live Captioning: start it from the menu bar menu's Start Live Captioning, or with a hotkey you set in Settings › Shortcuts › Voice; the same hotkey stops captions that are running. Requested by plkv_andrii.
- Live Captioning at the top or bottom of the screen now lays its controls out in a row with a wide caption area beside them, and you can resize the caption area by dragging its edges, at any position. Requested by plkv_andrii.

## iPhone and Android

- Added an Active group at the top of the iPhone and Android sidebars that gathers the chats waiting on you, failed, still running or holding an unread result, each with where it is and its state, and folds to one row.
- Changed the top bar of a Mac chat in the iPhone and Android apps: the sidebar and New chat buttons now sit together on the left, Side Panel and the chat menu on the right, the title stays centered between them, and messages fade out under the bar instead of ending at a line.
- Changed the iPhone and Android apps so a free account can pair with its Mac, use the Mac's chats and Mac Screen from the phone, and use the Avatar, which needed an Enconvo Cloud plan or lifetime license before.
- Fixed videos and files from a chat failing to play or download on the phone when the Mac has a large chat history.
- Fixed the Android app so a message sent while a reply is running shows in the chat at once instead of after the Mac answers.
- Fixed the first message of a new chat sent from the phone with a photo or file sometimes not showing in the chat while the reply did.
- Fixed pictures in a Friend Chat on Android opening the system's "Open with" list of other apps: a tap now shows the picture full screen inside Enconvo, where you can pinch or double-tap to zoom, swipe down to close, save it, or share it. Open With… stays in the picture's long-press menu.

## Also in this build

- Added Tutorials to Settings, where update videos and step-by-step walkthroughs play inside Enconvo and the ones you haven't seen are marked New.
- Added a card in the Chat Window sidebar that offers a version's update video the first time you use Enconvo after updating.
- Changed What's new in the Chat Window's settings menu to open Tutorials in Settings.
- Changed calls with a live video character so a silent call no longer uses up your daily video time: after a minute without anyone speaking her live picture rests until you talk again, after a minute and a half she asks "Still there?", and a minute later the call hangs up with a Continue button to pick it up again.
- Changed Share anonymous product analytics on the Mac to be on unless you turn it off, in the first-run guide or in Settings › General › Privacy; a Mac where you already set the switch keeps your choice.
- Fixed the Settings sidebar sometimes opening blank, with its menu items still clickable but not drawn.
