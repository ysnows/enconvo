# Enconvo 2.5.6 Beta 3

Thanks for testing Enconvo 2.5.6 Beta 3. This is the first beta signed by the
Enconvo company developer account. It also brings local MLX models into Settings,
Pixar-style Avatars, a narrated first-launch guide, and a native iPhone app.

## Highlights

- **Grant permissions once more after updating.** The Mac app is now signed by
  the Enconvo company developer account, and Enconvo clears the old permission
  entries so the macOS prompts work normally.
- **Run local MLX models from one Settings page** and use them in Claude Code,
  Codex, and other apps through local OpenAI- and Anthropic-compatible
  endpoints.
- **Puppy, Bear, and Cat are Pixar-style Avatars** with glossy eyes, real
  eyelids, and new moves.
- **A shorter first-launch guide** with four steps narrated in English or
  Chinese.
- **A faster native iPhone app** with voice chats with Puppy, settings synced
  with your Mac, and smoother chats.

## Setup and Permissions

- Changed the Mac app to be signed by the Enconvo company developer account.
  After updating, grant Accessibility, Screen Recording, Microphone, and other
  permissions once more.
- Changed the first-launch guide to a short four-step setup narrated in English
  or Chinese, with quick-start prompts on the last step. The feature tour is now
  an optional Explore page.
- Fixed the first-launch guide not appearing again if you quit before finishing
  it. It now resumes on the step you left.
- Fixed PopBar not appearing after you grant Accessibility or Input Monitoring
  while Enconvo is running.
- Fixed the permission window at launch sometimes opening behind other apps.

## Local MLX Models

- Added an MLX Models page to Settings where you can download a model picked for
  this Mac, load it, and set it as the default AI model.
- Added one model list with Recommended picks sized for this Mac's memory,
  trending Hugging Face models, a Downloaded tab, and downloads by Hugging Face
  repo id.
- Added OpenAI- and Anthropic-compatible endpoints at
  `http://localhost:54535/mlx_manage/v1` for chat, tools, embeddings, reranking,
  speech, and transcription. Settings has ready-to-copy setup for Claude Code,
  Codex, curl, and Python.
- Added prompt caching for local MLX chat and vision models, so follow-up turns
  start answering sooner.
- Changed MLX chat to stop right away when a request is cancelled.
- Changed the chat model picker to always list MLX, with downloaded models
  first.
- Fixed MLX models downloading again or hanging on load, and chats failing after
  a tool returned its result.
- Fixed tool calls from Gemma 4 and LFM2.5-VL vision models arriving as raw
  text.
- Fixed the Qwen3 and Jina rerankers, and local Whisper transcripts that ended
  with repeated text.

## Avatar

- Changed Puppy to a Pixar-style look with big glossy eyes and real eyelids that
  blink, squint, and close when it naps.
- Added Bear and Cat as new Pixar-style desktop Avatars, each with its own look,
  moves, and expressions.
- Changed Puppy to download from Avatar settings like the other characters. If
  Puppy was your Avatar, another installed character appears until you download
  it.
- Added new Puppy moves, including a wave, a bow, a cheer, and a backflip, and
  Puppy now reacts on its own when a conversation calls for it.
- Added instant expression reactions to clear emotional cues, even offline.
- Changed idle stance shifts to a natural, randomized rhythm.
- Fixed a newly downloaded character refusing to appear until Enconvo was
  restarted.
- Fixed Jev expressions never showing on Tia and other characters whose faces
  use only ARKit shapes.
- Fixed expressions staying off during calls when you are signed out or out of
  points.
- Fixed arms and legs briefly stretching during transitions.
- Fixed lighting changes leaving patches of clothing shading on the skin.

## iPhone App

- Changed the whole iPhone app to a faster native interface. Replies now show
  their formatting and fade in as they stream.
- Added voice input and real-time voice chats with Puppy.
- Added petting and tricks for Puppy, and Bear and Cat in iPhone Avatar
  settings.
- Added AI Model, Text-to-Speech, Image Generation, and Avatar pages to iPhone
  Settings, synced with your Mac.
- Added Read Aloud, Try Again, Find in Chat, Share, full-screen images, and an
  expandable message box to iPhone chats.
- Changed iPhone chats to follow the iPhone's text size, support VoiceOver, and
  animate at up to 120 Hz on ProMotion iPhones.

## Fixes

- Fixed transcribing imported videos in Recordings.
- Fixed long recordings failing with Soniox on slower connections. Recordings
  over 5 hours now stop right away with a message asking you to split them.
- Fixed the chat model picker not listing a provider right after its API key is
  saved.
- Fixed Read Aloud hanging when xAI is the default voice provider.
- Fixed local file links in chat answers showing as plain text.
- Fixed importing skills from a folder whose name contains spaces or non-English
  characters.
- Fixed new chats in the Chat Window starting with the built-in agent instead of
  your Default Agent.
- Fixed the local API going down at startup when a provider could not be loaded,
  or when a client stopped a streaming response.
- Fixed Image, Audio, and Video Compress failing on some files.
- Fixed legacy Excel `.xls` attachments failing to read.
- Fixed Open Link running parts of a link that contains `$(…)` or backticks as a
  shell command.
