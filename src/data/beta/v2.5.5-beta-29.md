# Enconvo 2.5.5 Beta 29

Thanks for testing Enconvo 2.5.5 Beta 29. This build makes corrections easier
to follow during long-running Agent tasks, improves xAI voice selection, and
streamlines the Doodle workflow.

## Highlights

- **Steer corrections now appear in the conversation immediately** while the
  current task and its tools continue running.
- **xAI voices now refresh dynamically** for personal credentials and Enconvo
  Cloud, with Ara selected by default.
- **Doodle now opens with the Arrow tool selected** for faster markup.

## Agent Conversations

- Changed queued Steer corrections to appear immediately with a Thinking
  indicator until the Agent applies them.
- Fixed earlier tool steps flashing or showing extra Thinking indicators while
  background tools continue and retain their results.

## Voice And Doodle

- Improved xAI voice refreshes with clear feedback when a refresh fails.
- Changed Doodle to select the Arrow tool when opened from double right-click,
  the keyboard shortcut, or the markup button.
