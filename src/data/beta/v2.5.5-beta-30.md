# Enconvo 2.5.5 Beta 30

Thanks for testing Enconvo 2.5.5 Beta 30. This build improves how active Agent
tasks respond to new messages, keeps command results in the right window, and
makes common SmartBar and Dynamic Island actions easier to reach.

## Highlights

- **Telegram and Discord messages can now steer an active Agent task** without
  interrupting its running tools or losing attachments.
- **Dynamic Island commands now return results to the window that launched
  them**, including shortcuts that use the current browser tab.
- **Video and audio downloads now show live progress** and finish with a file
  attachment that can be opened directly.
- **SmartBar opens with a more useful default command order** while preserving
  Favorites and keyword search relevance.

## Agent And Messaging

- Changed incoming Telegram and Discord messages to steer the current task
  automatically while preserving its tools, attachments, and typing indicator.

## Commands And Downloads

- Fixed foreground chat commands showing results in a different window from
  the one where they were launched.
- Added download and conversion progress, completed file attachments, and clear
  failure messages for streaming video and audio downloads.
- Added Online Video Downloader to the default Dynamic Island shortcuts.

## SmartBar

- Changed the default command order to prioritize Mavis, voice tools,
  recording, live captioning, screenshot tools, Read Aloud, and Writing Toolkit
  commands.
