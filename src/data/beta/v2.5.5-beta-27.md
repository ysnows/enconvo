# Enconvo 2.5.5 Beta 27

Thanks for testing Enconvo 2.5.5 Beta 27. This build expands the latest AI
model and image-generation options, improves account and device management,
and makes long conversations more dependable.

## Highlights

- **GPT-6 Astra, Grok 4.6, Gemini 3.8 Flash, GLM-5.3-Flash, and the DeepSeek V4
  family are now available** through their supported providers and Enconvo Cloud.
- **GPT Image 2.5 Flare and Sunburst add faster, more flexible image creation**
  with reference-image editing, transparency, output format, and quality controls.
- **Account device management is clearer and easier to recover** when you reach
  the device limit or move Enconvo to a new Mac.
- **Long conversations retain their context more reliably** after compression,
  message edits, deletions, and automatic continuation.

## New AI Models

- Added GPT-6 Astra with a 1.05M-token context window, image input, tool use,
  and Low through Max reasoning for OpenAI API keys, ChatGPT sign-in, and
  Enconvo Cloud.
- Added Grok 4.6 with 500K-token text and image input, tool use, search, and
  Low through XHigh reasoning for xAI API keys, xAI sign-in, and Enconvo Cloud.
- Added Gemini 3.8 Flash with 1M-token multimodal input, tool use, search, and
  Low, Medium, or High reasoning for Google API keys and Enconvo Cloud.
- Added Z.AI GLM-5.3-Flash with native multimodal input, a 1M-token context
  window, tool use, and built-in reasoning for Z.AI API keys and Enconvo Cloud.
- Updated DeepSeek to the new V4 family: V4 Flash, V4 Pro, and V4 Flash Vision
  (Experimental), and removed retired V3 and R1 models.

## Image Generation

- Added GPT Image 2.5 Flare and Sunburst for image generation and
  reference-image editing with OpenAI API keys or Enconvo Cloud.
- Added transparent output, selectable formats, and all supported quality levels.
- Changed new OpenAI image configurations and the Enconvo Cloud default image
  service to GPT Image 2.5 Flare while preserving existing saved choices.
- Fixed Enconvo Cloud image requests losing the selected output format or
  rejecting GPT Image 2.5 models after a service update.

## Account And Devices

- Added device management to Account so you can remove an old Mac, free a
  device slot, and explicitly activate the Mac you are currently using.
- Improved device-limit guidance, activation status, loading behavior, and
  account recovery after sign-in.
- Improved Account loading and refresh behavior so saved details appear sooner
  without restoring another user's data after account changes or logout.
- Fixed the Settings sidebar showing stale account details after sign-in,
  refresh, or logout.
- Added separate Lifetime and Cloud plan options for new users.

## Reliability

- Fixed earlier messages or summaries reappearing, disappearing, or becoming
  outdated after conversation compression, editing, deletion, or continuation.
- Improved context compression so earlier conversation and recent task progress
  are preserved separately while keeping the current request in focus.
- Fixed some AI requests failing because newly generated message IDs ended with
  an unsupported underscore.
- Fixed Cloud usage charges rounding exact half-point totals incorrectly.
