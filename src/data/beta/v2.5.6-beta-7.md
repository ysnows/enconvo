# Enconvo 2.5.6 Beta 7

Thanks for testing Enconvo 2.5.6 Beta 7. This build brings spoken Voice Command
replies with synchronized captions, smoother screen markup, and improvements
to the iPhone Companion experience.

## Highlights

- **Voice Command can answer out loud**, with captions that follow the spoken
  reply in Dynamic Island.
- **Keep the conversation in view**: Dynamic Island stays open with your words,
  the agent's progress, and its reply until you close it.
- **More reliable screen markup**: Screen Doodle keeps your annotations and
  opens the editor without distracting jumps or window animations.
- **Lighter avatars**: a new Minimal rendering quality, now the default on Mac
  and iPhone, uses far less GPU, CPU and battery.

## Voice Command and Dynamic Island

- Added Speak Replies to Voice Command, enabled by default and using your
  agent's configured voice.
- Changed reply captions to follow the spoken answer sentence by sentence,
  with controls to stop playback or open the conversation.
- Changed the Voice Trigger settings name to Voice Command.
- Fixed Dynamic Island sometimes opening as an empty bar after opening a
  Voice Command reply's chat.
- Removed the haptic feedback when hovering over the notch.

## Screen Doodle and Plugins

- Removed Screen Doodle's Fade Mode so annotations stay visible and appear in
  the screenshot you send to chat.
- Fixed the selected region jumping when the markup editor opens, and kept
  the originating Smart Bar or chat hidden until you finish.
- Fixed Try now prompts from Plugins and Connectors so the Send button
  appears and Return sends the prompt without needing to edit it first.

## Avatar

- Changed avatar Rendering quality to three levels, Minimal, Balanced and Best
  quality, with Minimal as the new default on Mac and iPhone; a saved Resource
  friendly choice now uses Minimal and other choices are kept.
- Changed avatars to draw less often while resting, listening or speaking,
  lowering GPU, CPU and battery use while motions and talking gestures stay
  smooth.

## iPhone Companion

These companion improvements require an updated iPhone app; the Mac installer
does not update the iPhone app.

- Changed new iPhone chats to use the most recently paired Mac by default,
  with a clearer Runs on picker showing each device's status.
- Changed the sidebar to combine and search iPhone and Mac chats, newest first.
- Changed New chat to open the home screen with the current run destination,
  and removed the separate message box from Remote.
- Changed voice calls to follow the chat's device, using your Mac's agent for
  Mac chats and the iPhone for local chats.
- Changed the Mac-chat model picker to show provider icons, Enconvo Cloud
  first, cross-provider search, live Mac model changes, and reasoning options.
- Changed the iPhone-chat model picker to show provider icons, your current
  model, cross-provider search, and an Add API key action.
- Added Mac agent model and reasoning controls to the iPhone home screen
  before starting a chat.
- Changed media sharing to open the share sheet immediately, download only
  when needed, share web videos as links, and reuse downloaded files.
- Added in-place reply text selection for copying, sharing, looking up, or
  asking AI about a passage.
- Fixed avatar motion requests during Mac-chat voice calls so they play on
  the iPhone, with better recognition of Chinese requests.
- Changed Mac connection settings to hide the TestFlight QR code while
  pairing, avoiding accidental scans of the wrong code.
- Fixed pairing errors to clearly explain when the devices use different
  Enconvo accounts and offer a way to sign out and scan again.
