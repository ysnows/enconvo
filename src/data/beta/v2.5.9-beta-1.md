# Enconvo 2.5.9 Beta 1

Thanks for testing Enconvo 2.5.9 Beta 1. This build makes the cards the agent draws in chat interactive, lets you start a voice chat from the iPhone's Action Button, adds a model picker to Claude Code and Codex chats, and shows the pictures and files an Agent makes the moment they are done.

## Highlights

- **Interactive cards in chat**: the cards the agent draws now have sliders, fields, choices and switches, progress bars and timelines, and live data from this Mac.
- **Voice chat from the Action Button**: start a voice chat with Enconvo from the iPhone's Action Button or the Shortcuts app without opening the app.
- **Pick the model for Claude Code and Codex**: a model and reasoning effort picker in new chats in the Chat Window, Smart Bar and Dynamic Island.
- **Finished work shows up at once**: pictures and files an Agent makes appear in the Dynamic Island's answer pill, the voice reply and the live call card.
- **Mac Apps as their own plugins**: Calendar, Contacts, Mail, Messages, Music, Notes, Reminders and Maps can each be turned on or off.

## Cards in Chat

- Added sliders, number and text fields, choices and switches to the cards the agent draws in chat, so you can try other values and see its totals update at once; the values stay when you reopen the chat, Reset values in the card's menu clears them, and its buttons can send them back to the agent.
- Added live data to the cards the agent draws in chat: a card can show your chats, the weather or what a plugin reports on this Mac as it is when you open it, and its buttons can run a plugin action after you confirm it.
- Added progress bars and timelines to the cards the agent draws in chat, so usage, budgets, itineraries and histories read at a glance.
- Changed a Memory the chat saved, changed or deleted to show as a card with its text: Undo takes back a save, Save again brings it back, and Manage in Memory opens Memory.
- Changed reading a web page in chat to show a card with the page's title, its kind and length, its text on request, and a switch to stop or allow reading that site.
- Changed the weather card in chats to come from the Weather plugin, as other plugins' cards do: it keeps its shape while the weather loads, and the Weather plugin's page lists it under Where it shows up, where you can turn off Inline Chat.
- Fixed a card the agent draws in chat coming up empty, or being drawn twice, when the agent used a part the chat doesn't have or wrote the card as code: the card now shows everything else it holds, and the agent redraws one that would show nothing.
- Fixed chat lists in the cards the agent draws so a narrow window shows each chat's status and time, shortening long titles instead of cutting off the right side.
- Fixed a security issue that let a card the agent draws in chat run code or show another web page inside it.

## Coding Agents

- Added a model and reasoning effort picker to a new Claude Code or Codex chat in the Chat Window, Smart Bar and Dynamic Island, which names the model the agent uses by default until you pick another; the pick becomes that agent's default for its next new chats.
- Added a coding agent mark, such as Claude Code's or Codex's, beside each chat's title in the Smart Bar and the Dynamic Island session lists.
- Added Paste, Copy and Insert Below for a finished Claude Code or Codex reply in the Smart Bar and the Dynamic Island, as other chats have.
- Fixed a new Claude Code or Codex chat started from the Smart Bar or the Dynamic Island not showing as running, so it had no stop button while the agent worked.
- Fixed a Claude Code or Codex chat in the Chat Window not showing its stop button while a reply runs that was started elsewhere or before the chat was opened.

## Voice, Dynamic Island and Deliverables

- Added a picture or file an Agent makes to the Dynamic Island's answer pill as soon as it is done: a click opens its chat in the Chat Window.
- Added a picture or video a voice command makes to the Dynamic Island's voice reply, under its answer, with every file the request asks for; a click opens its chat in the Chat Window.
- Added voice calls showing a finished picture, file, chart or card the Agent made right on its call card, while the Agent is still working.
- Added a picture or file a Hub task makes during a voice call to show under the call's reply on the call's HUD; a click opens its chat in the Chat Window.
- Added a quick action that minimizes every window of every app on the Mac, except Enconvo's, when a live call or voice command asks for it.
- Fixed a finished chat still showing Thinking on the Dynamic Island's Home while a voice call stays open.

## Mac Apps

- Changed Calendar, Contacts, Mail, Messages, Music, Notes and Reminders into separate plugins that show on the Mac Apps tab, so each one can be turned on or off on its own.
- Changed Maps into its own plugin, separate from the other Apple apps.
- Fixed Mac Apps sometimes showing Connect for an app that was already connected.

## Local LLM

- Fixed Storage on the Local LLM page showing less than the models folder takes in Finder: it now shows the folder's whole size, split into chat models and other models and files, such as speech, OCR and embedding models and unfinished downloads.
- Changed the Storage row on the Local LLM page to say No models yet until a model is downloaded, instead of showing 0 models and a dash.

## iPhone

- Added Start a Voice Chat to the iPhone app for the Action Button and the Shortcuts app: a press starts a voice chat with Enconvo in the Dynamic Island and on the Lock Screen without opening the app on iOS 18 and later, opens the app to start it when it can't, and hangs up a call that's on.
- Added a tip in the iPhone app, shown once after a voice chat, on how to start one from the Action Button, or from the Shortcuts app on an iPhone without one, without opening the app, with a button to Settings; Settings › Avatar & voice shows it again.
- Fixed KPI tiles missing from the agent's cards in the iPhone app when the Mac named them stat tiles, and added the cards' new progress bars and timelines there.
