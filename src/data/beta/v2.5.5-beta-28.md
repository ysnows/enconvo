# Enconvo 2.5.5 Beta 28

Thanks for testing Enconvo 2.5.5 Beta 28. This build improves image generation
with ChatGPT sign-in and makes existing Agent conversations more reliable when
you switch between AI models.

## Highlights

- **ChatGPT image generation now supports GPT Image 2.5 Flare and Sunburst**
  through GPT-5.6 Sol for both new images and reference-image editing.
- **Existing Agent conversations can switch models more reliably** while
  preserving tool results and compatible reasoning history.

## Image Generation

- Fixed OpenAI image generation and editing failing when older requests contain
  unsupported style or input-fidelity settings.
- Fixed image generation ignoring the configured provider when credentials use
  the global default.
- Improved ChatGPT image generation so Flare and Sunburst selections are
  accepted and model substitutions are reported clearly.
- Changed image generation and editing with ChatGPT sign-in to use GPT-5.6 Sol.

## Conversations And Model Switching

- Fixed errors when switching an existing Agent conversation to Gemini after
  using tools, while preserving tool results and subsequent tool execution.
- Fixed encrypted reasoning errors when switching models in an existing
  conversation without altering saved messages or valid reasoning history.
