# Enconvo 2.5.6 Beta 2

Thanks for testing Enconvo 2.5.6 Beta 2. This build brings desktop Avatars you
can talk to, GPT Live voice calls on the Dynamic Island, much faster browser and
app automation, and a simpler way to connect AI providers.

## Highlights

- **Talk to a desktop Avatar for each Agent** with its own look, voice,
  gestures, and motions, including Puppy, a built-in Avatar that works without
  downloading.
- **Call your Agent with GPT Live** from the Smart Bar, chat, or an Avatar, with
  a live transcript on the Dynamic Island, screen awareness, and automatic
  hang-up.
- **Browser and Computer Operator fast modes** finish well-scoped multi-step
  tasks in seconds and stop to ask before sensitive actions.
- **Connect providers with an API key or your ChatGPT, Claude, or Grok
  subscription**, and see how much of your subscription limits is left.
- **Pair the new Enconvo iPhone app** from Settings → Connections to continue
  chats, answer Agent questions, and get notified when a chat finishes.

## Avatar

- Added desktop Avatars for Agents, each with its own appearance, voice, and
  conversations, speech-synchronized lips, facial expressions, and contextual
  gestures.
- Added an Avatar gallery in Settings with character previews, downloads,
  deletion, and quality and voice options, with one Avatar per Agent.
- Added Puppy as a built-in Avatar that works right away, can be restored
  offline after you delete it, and wears a collar with a swinging bell.
- Added spoken requests for gestures, dances, and walking, so you can ask an
  Avatar to wave, dance, sit, come closer, or walk to a corner of the screen.
- Added an Avatar switch and an Avatar Motions list to the Dynamic Island, with
  one-click motion downloads when no motions are installed.
- Changed the Avatar right-click menu into Perform, Look, Character, and View
  groups, with a one-shot Close-up and Bring Avatar Back.
- Changed Avatars to use much less CPU while resting, with Resource friendly
  quality as the default while keeping quality choices you already saved.
- Fixed Avatar clicks, dragging, pinch zoom, and window jumps while resizing,
  zooming, or changing motions.

## GPT Live and Voice

- Added GPT Live calls on the Dynamic Island with a call HUD that shows what you
  say, the reply, and each step the Agent is working on, plus mute and hang-up.
- Added Live Talk to chat and the Smart Bar, with call transcripts saved to chat
  history and live Agent progress while you keep speaking.
- Added screen awareness, a doodle button, and a Live Screen mode so spoken
  questions can include what is on your screen.
- Added GPT Live Quick Actions that answer simple requests such as the weather,
  dark mode, or the time in about two seconds.
- Added automatic hang-up after a goodbye or a quiet period you choose, and a
  setting that continues recent voice conversations.
- Added a Realtime Voice choice between Enconvo Cloud points and your own OpenAI
  API key.
- Changed GPT Live to respond as soon as you finish speaking and to start Agent
  tasks faster.
- Added Gemini 3.8 Flash TTS and Flash-Lite TTS with the Gemini 3.8 voice
  library and style direction for tone, pace, and emotion.
- Fixed replies read aloud automatically using an old voice, and emoji being
  read aloud by name.

## Agents and Automation

- Added Browser Operator and Computer Operator fast modes that complete
  well-scoped multi-step tasks in seconds, stopping before purchases,
  deletions, and other sensitive actions.
- Changed agent mode to hand multi-step page tasks to the fast Browser Operator
  first.
- Fixed browser actions stalling on heavy pages and pausing before clicks in
  background tabs.
- Added a per-chat AI model and reasoning effort in the Chat Window, Smart Bar,
  and Dynamic Island.
- Added an Agent question card above the chat input, and questions from
  different chats now wait their turn instead of cancelling each other.
- Changed chat thinking and running-tool indicators to small animated orbs with
  shimmering status text.
- Fixed scheduled Agent jobs failing on every run, and added a plain-language
  schedule builder, run history, and delivery of results to IM chats.
- Added a Knowledge Base MCP server so Claude Code, Cursor, Codex, and Claude
  Desktop can search your knowledge bases.

## Providers and Models

- Changed provider Authentication to a clear choice between API Key and
  Subscription for OpenAI, Anthropic, Google Gemini, and xAI, migrating existing
  credentials automatically.
- Added subscription usage for ChatGPT and Claude sign-ins, showing how much of
  the 5-hour and weekly limits is left.
- Added provider profiles so a copy such as OpenAI 2 shares one key across every
  OpenAI feature, and grouped Credentials by provider.
- Changed credential validation to check your key without sending a test prompt
  and to refresh the model list afterwards.
- Added Claude Opus 5.5, GPT-6 Sol and Luna, Grok 4.7, GLM-5.3-FlashX, and MiMo
  V2.6 to BYOK and Cloud Plan, plus DeepInfra and Phala as new providers.
- Added Topview and OpenRouter image and video generation, Grok Imagine Video
  1.5, and the full Kie.ai model catalog.
- Fixed connecting to LM Studio, Ollama, and other model servers on another
  computer in your local network.

## Settings, Smart Bar, and Connections

- Added settings search across pages, providers, credentials, agents, and
  setting names.
- Added a Smart Bar Layout setting that opens the Smart Bar as input only, input
  and toolbar, or the full panel.
- Changed settings pages to keep their title fixed while the content scrolls,
  with Reset configuration in the title row or the ⋮ menu.
- Added a model picker to the PopBar result window toolbar.
- Added a Dev update channel in General settings for early development builds.
- Added the Enconvo iPhone app through TestFlight, which pairs with this Mac to
  browse and continue chats and answer Agent questions, and can also chat with
  AI models on its own using Enconvo Cloud points or your own API key.
- Added the Connections page for pairing the iPhone app with a QR code and a
  TestFlight download card, with shortcuts in the Chat Window sidebar and the
  Dynamic Island.
- Changed Telegram and Discord verbose mode to show live tool progress, and
  messages sent during a task now steer it.
- Changed the Skills page to a card grid with source tabs and an Import button.
- Removed the Retry button under AI replies and the default right Shift
  long-press for Memory voice notes, which can still be assigned in Voice Note
  settings.

## Fixes

- Fixed Claude requests failing after parallel tool calls, and Anthropic OAuth
  requests failing on the Anthropic provider.
- Fixed transcription and dictation silently returning empty text when the
  provider fails; they now show the provider's error.
- Fixed shell commands and terminal windows failing after agents ran many
  commands.
- Fixed dragging files onto the Dynamic Island and file pickers opening
  underneath it.
- Fixed Return in the Chat window sometimes triggering Paste.
- Fixed the first launch on a fresh install sometimes failing to index commands.
