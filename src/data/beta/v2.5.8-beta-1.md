# Enconvo 2.5.8 Beta 1

Thanks for testing Enconvo 2.5.8 Beta 1. This build adds Codex, Antigravity and GitHub Copilot as agents and providers, a new Orchestrator Board for projects, and OpenRouter speech support.

## Highlights

- **Orchestrator Board** for a project: plan and assign coding tasks, each in its own branch and worktree, and merge them when they are ready.
- **Codex as a coding agent** in chats, with its own models, reasoning levels, permission modes, file change cards and subagents.
- **OpenRouter for speech**: text-to-speech and speech-to-text models work with one OpenRouter key.
- **Antigravity and GitHub Copilot** as AI model providers, signed in with your Google or GitHub account.
- **Smart Bar switches input source** when it opens and back when it closes.
