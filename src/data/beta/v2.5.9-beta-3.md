# Enconvo 2.5.9 Beta 3

Thanks for testing Enconvo 2.5.9 Beta 3. This build adds Phonon, a free voice that runs on your Mac and iPhone, lets you see and make Quick Actions for Voice Command and Live Talk, lets agents hand work to each other, gives the built-in plugins and hotkeys their own settings, and brings a Side chat and Live Talk settings to the iPhone app.

## Highlights

- **Phonon, a free voice on your devices**: an English voice from Gradium that reads answers aloud and speaks in Live Talk and Voice Command almost at once, on Macs with Apple silicon and macOS 15 or later and on iPhones with iOS 18.
- **Quick Actions**: Settings › Voice Assistant › Quick Actions shows what Voice Command and Live Talk can run at once, and you can make your own from a sentence or from built-in actions, Shortcuts, apps, links and scripts.
- **Agents calling agents**: any agent, Claude Code and Codex included, can ask another agent to do part of its work and get the answer back, and AI apps on your Mac can ask your agents for work over MCP.
- **Built-in plugins with their own settings**: Clipboard History, File Search and Browser Bookmarks get settings pages under Plugins, Mini Apps get shortcuts, aliases and paging, and File Search answers as you type without Full Disk Access.
- **Every hotkey in one place**: Settings › Shortcut lists every hotkey, finds what uses a key combination, and warns about clashes with Use it here.
- **iPhone Side chat and Live Talk**: ask a side question in a Mac chat, choose how voice chats listen, think and speak, and let Parakeet, Fluid Speech Mini and Phonon hear and speak on the iPhone itself.
- **A task list in the Dynamic Island**: with three or more things going on, one Tasks chip opens a list grouped into Needs you, Failed, Running and Done.

## Phonon and Voices on Your Mac

- Added Phonon, a free on-device English voice from Gradium with 37 voices, as a Text-to-Speech provider on Macs with Apple silicon and macOS 15 or later; its 137 MB model downloads from its settings card or the first time it reads, and the Mac's own voice for each language reads answers in other languages.
- Added Phonon as a voice for Live Talk and Voice Command on the Mac, and for calls from the iPhone or Android app to a Mac chat: choose it under Choose a voice, and her English replies start speaking almost at once, made on the Mac as they're spoken, while sentences in other languages are read by the Mac's own voice for that language at the same volume.
- Changed calls that speak with Kokoro or Qwen3-TTS on this Mac to play each sentence as soon as the model makes it, without waiting for the rest of its piece, and Qwen3-TTS to start speaking before a sentence is finished.
- Changed Read Aloud and spoken replies with a voice made on this Mac, such as Kokoro, Qwen3-TTS or Phonon, to start speaking each sentence as soon as its first audio is made, instead of after the whole sentence.
- Fixed Qwen3-TTS on this Mac sometimes going on making silence after a sentence, or for minutes without stopping, which left long pauses and held up every other local voice meanwhile.
- Fixed the local MLX runtime crashing, and stopping every local model, when Qwen3-TTS speech was streamed, such as from the OpenAI-compatible speech API on this Mac.

- Added Eleven v4 Turbo, Eleven v3 Conversational and Eleven Turbo v2 and v2.5 to ElevenLabs on Enconvo Cloud.

## Quick Actions

- Added Settings › Quick Actions, where you see every Quick Action Voice Command and Live Talk can run at once, turn any of them off, choose whether they run in Voice Command, Live Talk and calls from your phone, try a phrase to see which one she'd pick, and see what ran lately and, in your language, why a run stopped.
- Added your own Quick Actions: say what should happen, in any language, and Enconvo drafts the steps in that language, or build one yourself from built-in actions, your Shortcuts, apps, links, Enconvo commands and scripts; she runs its steps exactly as saved when what you ask matches it, and can check with you first.
- Changed Settings to group Voice Command, Live Talk and Quick Actions under Voice Assistant.
- Fixed saying no to a Quick Action she just offered in a call turning down a task's request you hadn't heard yet.
- Fixed Settings › Quick Actions staying on a quick action deleted elsewhere after a save or switch was refused, and showing a failed app or command search as no matches.

## Agents Calling Agents

- Added agent calls, so any agent, Claude Code, Codex, Grok Build and Antigravity included, can ask any other agent to do part of its work, directly or from a workflow it runs, and get the answer back, in a Permission mode no wider than its own; each call shows as one line in the caller's chat with what it has spent so far, counting the agents it called in turn, says when the called agent waits on a question and whether that's for the calling agent or for you, and opens the called chat; the called chat says who called it, and stopping the caller stops its calls too.
- Added questions between agents, so when an agent you asked for help needs a decision, the agent that asked answers it or leaves it to you, and you see it only once that agent passes it on or finishes.
- Added Connect AI Clients to the Agents page, so AI apps on your Mac such as Claude Code in a terminal, Codex CLI, Cursor and Claude Desktop can ask your agents to do work over MCP and answer the questions your agents ask them, with a switch to turn it off.
- Fixed an agent that starts another agent's run directly, which could run it inside its own chat or inside a chat you were in; the run now gets a chat of its own and works in a Permission mode no wider than the agent's.
- Fixed an agent that works with a Coding agent chat being able to reach past its own Permission mode, by switching that chat to a wider mode, adding a message to a turn running in a wider mode, starting a Subagent, or using the Agents MCP entry you added to Codex or Claude Code for Connect AI Clients.
- Fixed an agent being able to skip asking you before running a script or another action that needs your approval, by naming that action inside its request instead of calling it directly, or by writing its address in a roundabout way.
- Fixed an agent being able to run an Enconvo command you would be asked about, or a script, by putting it in a Quick Action or writing its route in other letter cases.
- Fixed agents running a command that deletes files, stops programs or runs as administrator without asking first when the command names the program by its full path, such as /bin/rm.
- Fixed workflow steps that run Claude Code, Codex, Grok Build or Antigravity, which failed with an invalid session, and Coding agents that call one of your Agents by its name, which wasn't found.
- Fixed the Agent going on without a skill it loaded in the same step as opening a web page.
