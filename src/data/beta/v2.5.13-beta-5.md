# Enconvo 2.5.13 Beta 5

Thanks for testing Enconvo 2.5.13 Beta 5. This build adds Vim Mode to the message box and lets your list keys work everywhere, adds Agentic Inbox to Email, puts apps back as they were after Computer Use, shows a live card for calls an Agent places to you, and shows messages you send mid-reply right away on the iPhone and Android apps.

- Added Vim Mode for the message box in Settings › General › Keyboard, modeled on Claude Code's: Esc goes to Normal mode and the box shows the mode at its bottom right; motions (h j k l, w b e, 0 ^ $, gg G, f t ; ,), operators with counts (d c y, dd cc yy, D C Y), text objects (iw, i", a( and the rest), x r ~ J, p P, visual and visual-line selection, undo, redo and . all work, and a mention chip counts as one character. In Insert mode Return, @ and / behave as before.
- Added `/vim` to the message box, which turns Vim Mode on or off without opening Settings, as in Claude Code.
- Changed Navigation Bindings to live in Settings › General › Keyboard and to hold everywhere instead of only in the Smart Bar: the keys you pick (macOS: ⌃N ⌃P ⌃F ⌃B, or Vim: ⌃J ⌃K ⌃L ⌃H) move through every list, menu and picker that takes the arrow keys, in the Smart Bar, the Dynamic Island, the action panel, the model picker, native list windows, and the Chat Window's and Settings' lists, menus, mention and slash pickers. With Vim, plain J K H L also move a list or menu while no text field has the focus. Your saved choice carries over.
- Changed Navigation Bindings and Vim Mode to be fully separate: the bindings move lists and menus only, so ⌃J ⌃K ⌃L ⌃H keep their normal editing meaning in a text field, and Vim Mode alone decides how the message box is edited.
- Fixed Escape in Vim Insert mode and in open composer menus so it leaves editing or closes the menu before stopping a reply or waiting loop.
- Fixed Vim undo and redo so each command and its inserted text stay together, arrow keys in Visual mode so the selection shown matches what a command edits, and line motions in messages that start with a blank line.
- Fixed keyboard settings reverting after a delayed read while preferences were being saved, and native list shortcuts interrupting input-method composition.
- Added Agentic Inbox to Email: a mailbox on a Cloudflare email agent (such as mail.enconvo.com), read and sent through the agent's MCP server with its own sign-in and no password. Add a mailbox now shows the providers as logo tiles (Gmail, iCloud, Outlook, Microsoft 365, Yahoo, Fastmail, QQ Mail, 163 Mail, Agentic Inbox, Other IMAP); picking Agentic Inbox lists the MCP servers that offer mailbox tools, signs in, and lets you pick one or more of its mailboxes. New mail is checked every 2 minutes. Mail from an Agentic Inbox goes to one recipient at a time, without Cc, Bcc or attachments, and the compose form names what's in the way with a fix for each. An expired sign-in shows Sign In Again, and mail waiting to go is sent once you're back.
- Changed Computer Use to put apps back as they were when an Agent is done with them: an app the Agent opened quits, windows it opened in an app you already had open close, an app that was hidden hides again, and the app you were in comes back to the front. The Agent keeps the app or window it shows you a result in, and anything with unsaved work stays open.
- Added a live call card for calls an Agent places to you: after you answer, the card stays on with a moving waveform, the talk time and the line last said, and End call hangs up on your phone; while it rings, Cancel call stops it; afterwards the card shows the talk time and Open recording.
- Fixed the iPhone and Android apps hiding a message you send while a reply is running: it now shows in the chat as soon as the Agent takes it in, under what the reply had written so far, as on the Mac.
- Fixed an Agent calling you on your own account in Video Conference: asked to make a conference link and send it to yourself, it rang your own devices. Making or sending a link no longer rings anyone, and a friend whose name only begins with yours is no longer called in your place.
- Fixed deleting chats from the sidebar, Clear All and removing a command's chats leaving their turns running in the background; they now stop first, and deleting a chat also ends the call to a friend its Agent placed.
- Added a status mark to collapsed Projects, Chats and Phone chats sections in the Chat Window sidebar for the chats they hide (waiting on you, failed, running, results not opened, with their count). Clicking the Dock icon while its badge counts chats opens the section, Project and Worktree of the first chat that needs a look and scrolls to its row, without opening the chat. The badge counts only chats the sidebar lists.
- Added resizing the Chat Window sidebar: drag its right edge (240 to 480 points wide), or double-click the edge to go back to the default width.
- Added resizing the selected area in Screen Doodle: drag any of its eight handles to make it larger or smaller; your marks keep their place, and Esc during a resize restores the previous area.
- Changed Full access so it no longer stops to ask before commands that used to ask in every mode; it now asks only before a command that would wipe something, such as deleting `/`, your home folder, the working folder or a whole volume, or erasing a disk.
- Fixed the "Thinking…" line vanishing while a model thinks before any of its thinking text arrives; it now stays from the first moment until the thinking is done.
- Fixed attaching an image or file to a new chat opening a gap between the project row and the starters under the composer.
- Fixed files, screenshots and pictures dropped onto a narrow Chat Window with the sidebar open doing nothing; they are now attached to the chat under the sidebar.
