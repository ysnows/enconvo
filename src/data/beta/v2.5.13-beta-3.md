# Enconvo 2.5.13 Beta 3

Thanks for testing Enconvo 2.5.13 Beta 3. This build lets agents make and answer calls through Your iPhone, makes pairing computers clearer and adds SSH hosts for agents to work on, and brings group chats and reactions to Friend Chat.

## Highlights

- **Agents make and answer calls through Your iPhone**: calls work on macOS 27.3 and can press keys in automated phone menus; Answer my calls takes tasks from your own numbers, picks which Mac answers first and recognizes callers in Contacts; and a call card sets up a phone line right in the chat.
- **Better computer pairing, and SSH hosts**: Settings › Connections lists Phones, Computers and SSH hosts with a page for each and Stop all access; pairing shows which computer controls which and asks with a notification; each computer can open as an app of its own with a Dock icon and a shortcut; and you can @ a paired computer or an SSH host in the composer, add SSH hosts from your SSH config with nothing installed, and let agents run commands there, asking first as the chat's Permission mode says.
- **Friend Chat gets group chats, replies and reactions** on the Mac, iPhone and Android: start a group and @mention people, see who has seen your message, react with any emoji or reply with a quote, and see unread friend and group messages on the Dock icon.
- **Subagents do more**: Antigravity, Grok Build and Muse Code join Claude Code and Codex, each Subagent that changes files gets its own git worktree, Subagents can run on another paired computer or in a pipeline that resumes where it failed, and your own helpers from `~/.enconvo/agents`, `~/.claude/agents` and `~/.codex/agents` show up in every chat.
- **Projects**: a Project chat's work shows on the Board as a card that follows it to Done, and you can hand part of a request to a model by name, such as Claude Code on Opus 5.5.
- **Claude Fable 5.2**, Anthropic's most capable model, on Enconvo Cloud and with your own key or Claude subscription, with up to 1M tokens of context.
- **Artifacts in Desktop Sync**: every artifact and its versions reach your other Macs, and conflicting edits keep both versions.
- **Automations**: a Time limit from 15 minutes to 8 hours, and every run now shows in Chats.
- **Approvals and results in the Dynamic Island's task list**: allow or decline right in its row, and open the chat where it started.
- **Run AI Commands from anywhere**: `files=` in Enconvo links, `enconvo ai-command run`, the `ai-command/run` route, and a Link, CLI and API row to copy them.
- **Expo as a Plugin Store plugin** with the Expo team's official skills and the Expo MCP Server, replacing the Expo Connector.
- **Mac chats on iPhone and Android, sturdier**: replies stay in view, chats switch faster, nothing you send is lost, and Live Talk shows words as they are said.
- **Workspaces**: a Workspace menu in the Chat Window sidebar from the start, with a short guide to your first Workspace.

- Fixed agents being unable to press keys on calls through Your iPhone, so they can now get through automated phone menus such as a carrier's service line.
- Fixed calls through Your iPhone to a contact saved under a short name, which failed saying macOS never showed the call prompt.

- Added letting agents run commands on another of your paired computers when that computer allows Terminal for this Mac, asking first as the chat's Permission mode says, with Agents and Commands switches on each computer's page in Settings › Connections.
- Changed Settings › Connections into three lists, Phones, Computers and SSH hosts, where each phone and computer opens its own page with what it can do, and a Who can reach this Mac row with Stop all access to cut every phone and computer off at once.
- Added an app of its own for each paired computer on the Mac: Open in its own window shows that computer's chats in a window with its own Dock icon in the computer's color, and Keep in Dock in its ⋯ menu keeps the icon there to open it later; the Settings window also gets its own Dock icon while it is open.
- Added a choice of where each paired computer opens, in the Chat Window or in its own window, and a shortcut that brings it up from any app on the Mac, both under How it opens here in Settings › Connections and in the computer's ⋯ menu.
- Added a short guide after pairing a computer that sets where it opens (in the Chat Window or its own window), gives it a shortcut that brings it up from any app, and shows what you can do on it; open it again any time from the computer's ⋯ menu › How to use.
- Changed Pair a computer so it always shows which computer controls and which is controlled, can be started from the computer you're at by asking the other one to allow it, lets you choose what the other computer can reach while allowing it, and on the Mac opens the newly paired computer in the Chat Window instead of a separate window.
- Changed Settings › Connections to list each paired computer once with which way it controls, and Open on a computer there now opens it in the Chat Window on the Mac.
- Changed a request from another computer to pair with your Mac to arrive as a notification with Show and Not now, instead of opening the Chat Window on its own; Not now tells the other computer right away.
- Added a note on your Mac after another computer pairs with it, saying what that computer can use here, with Change to adjust it in Settings › Connections.
- Fixed a request to pair from another computer staying on your Mac after that computer quit or lost its connection.
- Fixed Remote on a Mac using another Mac failing some requests during a burst of activity, which now wait their turn instead.
- Fixed handing a task to another Mac waiting silently while that Mac asked for approval; the chat now says the other computer waits for approval on its own screen, and what for.
- Fixed Ask for approval asking before an agent reads how to use your other computers, and the approval for handing a task to another computer showing only a route; it now names the computer and the task.
- Fixed approvals for work on another paired computer showing the computer's id instead of its name, in the card and in what Allow for this chat covers.
- Fixed testing an SSH host on your local network telling you to check its address when macOS was holding the connection for its Local Network permission; it now says to allow Local Network for Enconvo.
- Fixed the composer's first @ menu after Enconvo starts showing no Computers.
- Fixed a second SSH host for a computer you already reach over SSH taking over that computer's entry and listing it twice; the first host stays linked, and removing it links the other one.
- Fixed turning off Commands on a computer's page leaving its SSH host free to run commands.
- Fixed a wrong SSH password or passphrase reopening its box with no word that it didn't work.
- Fixed the Computers list in Settings › Connections showing what a computer allows from when the page opened, until you opened it again.
- Fixed a computer with two saved SSH hosts showing the wrong one on its page, so Before each command and Remove SSH access changed a host other than the one in use.
- Changed the Allow Local Network card of an SSH host test to open System Settings at Privacy & Security, where Local Network is.
- Changed Pair a computer's Chats and tools choice to say that the other computer's agents can then run commands on this one.

- Added replies and emoji reactions to Friend Chat on the Mac: hover or right-click a message to react with a quick emoji or any emoji, or to reply with a quote, click a reaction to add or remove yours, and click a quote to jump to the original message; the Chat tab of a friend call shows the same quotes and reactions and lets you react and reply there too.
- Added group chats to Friend Chat in the iPhone app: start a group from the + in the Friends list, @mention people, see who has seen your message, and rename a group, change its picture, set its notifications, add or remove people, hand it on or leave it from its details.
- Added group chats to Friend Chat in the Android app: start a group from the + in the Friends list, @mention people, see who has seen your message, and rename a group, change its picture, set its notifications, add or remove people, hand it on or leave it from its details.
- Added replies and emoji reactions to Friend Chat in the iPhone app: hold a message to react with a quick emoji or any emoji, or to reply with a quote, tap a reaction to add or remove yours, hold it to see who reacted, and tap a quote to jump to the original message.
- Added replies and emoji reactions to Friend Chat in the Android app: hold a message to react or reply, tap a reaction to add or remove yours, and tap a quote to jump to the original message.
- Added an unread count on the Enconvo Dock icon for friend messages, which follows chats read on any device and leaves out muted chats.
- Changed the iPhone app's Friend Chat message bar to a lighter messenger look, with a flat text field on its own band and thin, evenly sized voice, emoji and + buttons.
- Fixed conference links tapped in a chat on iPhone opening the web join page, so they now join the call in the app.
- Fixed an agent calling a friend for you taking someone talking near them as their answer and moving on; it now keeps waiting, or asks again, until they answer it.
- Changed conference Notes so each person turns their own notes on and off and gets their own Doc, instead of the organizer's Notes turning them on for everyone and leaving nobody else in control.

- Fixed conference notes appearing under Earlier for people they couldn't be shared with.

## Subagents and Projects

- Added Antigravity, Grok Build and Muse Code as Subagents beside Claude Code and Codex, and a Subagent's card now shows its Coding agent's icon, where it works, and the tool calls, time and tokens it used.
- Added a git worktree of its own for each Subagent that changes files while another one does, so two Subagents never overwrite each other's work; a worktree with no changes is removed when its Subagent finishes.
- Added running a Subagent on another of your paired computers, so an agent can hand a task to that computer's agent or a Coding agent there.
- Added your own Subagent helpers from `~/.enconvo/agents`, `~/.claude/agents` and `~/.codex/agents` to every chat, and the skills, MCP servers, turn limit, background and worktree settings in Claude Code agent files now take effect.
- Added Subagent pipelines, so an agent can run a planned set of Subagents in one step, such as the same check over a list of files, and resume a failed run without running the finished Subagents again.
- Added Chat tasks to Project Boards: when a chat in a Project changes files or runs a command, its work shows as a card that follows the chat to Done with a short summary and the files it changed, opens the chat when clicked, and lets the Project lead steer clear of the same files.
- Added handing work to a model by name in a Project's Lead chat, also when the Project has no members, and in a chat where you @mention other Agents: ask to give part of a request to a model such as Opus 5.5 and Mavis does that task on it, or name an Agent and a model together, such as Claude Code on Opus 5.5, or Codex, Grok Build, Antigravity or Muse Code on one of their own models, to run that Agent on it for that task only, even when that Agent isn't one of the Project's members; the plan's card and the Board show the model beside who does it, the lead asks when the name could mean several models or none, and the plan waits for Start while you are signed out.
- Fixed Codex, Claude Code and Antigravity members of a Project asking you to approve commands the Project's Permissions setting allows: they now work in the lead's mode on every task, and Approve for me runs Codex in its own Approve for me.
- Added worktree cleanup to Project settings: a worktree is now archived, and its folder removed to free disk space, once none of its chats is left in the chat list or after its chats sit idle for 7 days (3, 14 or 30 to choose), while a worktree with uncommitted changes stays and Restore brings an archived one back.
