# Enconvo 2.5.8 Beta 2

Thanks for testing Enconvo 2.5.8 Beta 2. This build adds new Automations triggers, more ways to take coding agent chats to your terminal, diagrams in chat replies, and a Location & Maps plugin.

## Highlights

- **New Automations triggers**: run an automation when a meeting starts, each time you log in, or when a webhook request arrives.
- **Coding agent chats in your terminal**: Continue in Terminal or iTerm, Copy command, and Fork for Claude Code, Codex and Grok Build chats.
- **Diagrams in chat**: Mermaid blocks in replies and Markdown previews now draw as diagrams.
- **Location & Maps plugin**: travel times, when to leave, and places nearby or anywhere, using Apple Maps with no API key.
- **MiniMax M3.1 Flash** on Enconvo Cloud and with your own MiniMax key, at half the price of MiniMax M3.

## Automations and Workflows

- Added a meeting trigger to Automations, so an automation runs when a meeting starts in Zoom, Teams, FaceTime or a WeChat call.
- Added a login trigger to Automations, so an automation runs once each time Enconvo starts after you log in.
- Added a webhook trigger to Automations: a request sent to the automation's address runs it, and a request sent while your Mac is off runs when it is back and signed in.
- Changed webhook automations to receive the event a sender names, such as GitHub's push or issues, and to accept requests up to 25 MB.
- Added a Starts when line to a workflow's page that lists the automations which start it on an event, such as a file appearing, an app opening or an email arriving, and the Schedule line no longer says paused for an automation that was never on a schedule.
- Added a Starts when line to a workflow's Start node in the visual editor, naming the automation trigger that starts it, such as a file appearing or an app opening, with a count when there is more than one.
- Added an Add trigger button to a workflow's Start node in the visual editor, which opens Automations on a new automation already started with the workflow's name.
- Changed a workflow's approval step to wait 24 hours for an answer before it's skipped, up from 1 hour; a step can still set its own wait.

## Coding Agents

- Added Copy command to the Copy menu of Claude Code, Codex and Grok Build chats: it copies the command that continues the chat in any terminal, such as Ghostty, Warp, an editor's terminal or one over SSH, and Enconvo lets go of the chat first so the two don't write over each other.
- Added a terminal button to each session in the new-chat page's Claude Code, Codex and Grok Build session lists: it continues that session in Terminal, or iTerm when you have it, without making it a chat first, and brings forward the terminal that already has it open instead of opening it twice.
- Added Continue in Terminal, or Continue in iTerm when you have it, to the ⋯ menu of Claude Code, Codex and Grok Build chats.
- Added a Fork button when Continue in Terminal can't take a Claude Code or Codex chat because it's working: it opens a copy of the chat in the terminal, and the chat keeps working.
- Fixed Continue in Terminal opening a second terminal on a Claude Code, Codex or Grok Build chat that a terminal already has open, so both wrote to it; it now brings that terminal forward.
- Fixed Continue in Terminal on a Claude Code chat opening the terminal before the chat's own Claude Code had finished closing, so the two no longer share the conversation for a moment and tools that follow Claude Code sessions no longer see it end just after it opens.
- Fixed Continue in Terminal and Fork for Codex chats failing at once with Codex 0.155 or older.
- Added images Codex generates to Codex chats: a picture Codex makes now shows in the reply (and after reopening the chat), with a line while it is being made and a note when it couldn't be made.
- Changed Codex chats to show the image Codex looked at inside its Read step, as Claude Code chats already do.
- Fixed Stop in Codex chats leaving Codex's subagents working in the background: stopping a chat now stops them too.
- Changed how Enconvo checks Codex's account: pages asking at the same time share one check, and Enconvo's own checks run one at a time, so two Codex processes can't refresh your ChatGPT sign-in at once and sign Codex out.
- Changed how Enconvo checks Codex's account and lists a folder's Codex sessions: it starts Codex without its plugins, so each check no longer updates Codex's plugin lists from the internet or leaves that update running after it ends.
- Changed Codex, Grok Build and Antigravity chats to keep the Mac from going to sleep on its own while they work, as Claude Code chats already do, so long turns are no longer cut off.
- Fixed Codex installed with npm sometimes staying open in the background after its chat closed, still holding the conversation, when Codex was slow to stop; Grok Build and Antigravity chats stop the same way now.
- Fixed Claude Code chats in folders whose names use accents, Korean or Japanese: Enconvo now finds their history, subagent details and restore points, notices when the session is open in a terminal, and opens it from the session list without a wrong-folder error.
- Fixed Codex chats whose ChatGPT sign-in expired or was revoked: the chat now says to sign in again from Enconvo's Coding agent settings, and the next message uses the new sign-in without reopening the chat.
- Fixed Grok Build turns that failed or ran into the usage limit ending without a reason: the chat now shows why the turn failed, or that the usage limit was reached, instead of a bare "Internal error" or nothing.
- Fixed Claude Code chats for people who set CLAUDE_CONFIG_DIR in their shell profile: Enconvo now finds their sessions, history and restore points in that folder instead of looking in ~/.claude.
- Fixed Claude Code chats whose picked model is no longer available failing every message: the chat now switches to the default model, says so, and the next message runs.
- Fixed text pasted into Claude Code in Terminal showing wrapped in pasted_content tags when the chat is opened in Enconvo: it now shows as it was pasted.

## Voice and Dynamic Island

- Changed Voice Command on the Mac to open an app, run a quick action such as dark mode or next track, or start a browser search as soon as you finish speaking, about a second sooner than before.
- Changed Voice Command on the Mac to do two or three quick things you ask for in one go, such as opening two apps and a Google search in either order, or opening Chrome and searching in it, right away instead of starting a task for them.
- Fixed Voice Command talking over you when you press to speak again before its answer to what you said before has come back: it stays quiet while you hold the key, and tells you that result along with its answer to what you say next.
- Added browser search to voice calls on the Mac: ask to search the web in your browser, or with Google, Bing, Baidu and other search engines, and the results page opens in your default browser or the one you name.
- Changed app opening in voice calls to find apps by their names in other languages or the names people call them, such as 微信 for WeChat, 备忘录 for Notes or VS Code for Visual Studio Code, and to open them faster.
- Fixed voice calls waiting a second or more before each answer when Enconvo Cloud's ElevenLabs voice has no credits left: the call now switches to its backup voice at once and keeps it for the rest of the call.
- Changed Natural lip sync on Macs with Apple silicon to download its model on its own the first time an Avatar opens or speaks, so Avatars get natural lips without a visit to Settings › Avatar; a model you cancel or delete there stays off until you download it again.
- Changed the Dynamic Island to stop showing Thinking chips for Agents working in other chats above the message box while a chat is open; Home still shows them when no chat is open.
- Fixed the Dynamic Island keeping an empty row above the message box after its last activity chip went away.
- Fixed an Agent chip in the Dynamic Island's Home staying on Thinking, and the closed island saying Working…, after its chat had already finished.
- Fixed the row of buttons under the message box in the Dynamic Island's Home being cut off by the island's bottom edge when activity chips show above the message box.
- Changed the Spotify and Apple Music buttons in the Dynamic Island's Home to start listening as soon as you click them, switching from another app's call if one is on, and to ask you to connect at once when the app isn't connected.
- Changed the Dynamic Island Home's shortcuts to put the Spotify and Apple Music buttons last, just before Connections.

## Plugins and Smart Bar

- Added a Location & Maps plugin: Agents can now tell how long a trip takes by car, on foot or by public transit and when you need to leave to arrive on time, and find places by name or kind near you or anywhere, using Apple Maps with no API key.
- Changed this computer's location command from `enconvo weather/current_location` to `enconvo location/current_location`.
- Added diagrams to chat replies and Markdown previews: a Mermaid block now draws as a diagram in the chat's colors, growing as the reply writes it, with a button to switch to its code; a block that can't be drawn shows its code and the line at fault.
- Changed app search in the Smart Bar to find apps by their names in other languages too, such as 微信 for WeChat or 谷歌浏览器 for Google Chrome.
- Changed the PopBar Extensions tab on the Plugins page to be called PopBar.
- Changed the PopBar tab in Plugins to drop the line and buttons above its list; Add PopBar extension and Import from PopClip are now in the Add menu.
- Removed Connect AI Clients (MCP) from the Computer Use and Browser Use plugin pages, and turned off the Computer Use and Browser Use MCP servers that AI apps such as Claude Code, Codex and Cursor could connect to.
- Removed the Browser Extensions list from the Computer Use plugin page; it stays on the Browser Use page.

## Models and Enconvo Cloud

- Added MiniMax M3.1 Flash to Enconvo Cloud and to your own MiniMax API key: it costs half as much as MiniMax M3, answers about three times faster, gets the Pro and Max plan discounts, and is now the default model for a MiniMax key.
- Changed what the agent hears when OpenAI no longer accepts the ChatGPT sign-in used for images: it is told to have you sign in again and that Enconvo Cloud can make the image instead, so it no longer tries other providers' routes first.
- Added a Cloud points button beside the usage button on Enconvo Cloud providers in Settings, showing the points used in the last 30 days with a trend line, your balance, today's points and the daily average on hover, and opening Points usage when clicked.

## iPhone

- Fixed the coding agent mark at the end of sidebar and Mac chat rows in the iPhone app so it lines up with the laptop icons.
