# Enconvo 2.5.6 Beta 10

Thanks for testing Enconvo 2.5.6 Beta 10. This build brings your Macs closer
together, makes Memory easier to manage, and adds more ways to get everyday
work done. Please try the changes below and share any issues you find.

## Highlights

- Added Sync across your Macs for chats, Projects, settings, workflows, skills, and knowledge bases.
- Changed Memory into a shared Knowledge Base where you can review, edit, tag, and search what your agents remember.
- Added workflow recovery, drag-to-reorder steps, multi-selection, keyboard shortcuts, and easier scheduling.
- Added Clipboard History, Snippets, Quicklinks, an Emoji Picker, Window Management, and Raycast-compatible extensions to the Launcher.
- Fixed stuttering in long chats, streaming replies, code blocks, tables, and voice-call captions.
- Changed voice tasks to start faster and report their progress, with more natural calls and smaller Avatar downloads.

## Interface Languages

- Fixed the Mac menu bar, main feature shortcut names and descriptions, Dynamic Island button hints, and invite dialogs showing English in other languages, with the menu updating immediately when you switch languages.

## Sync

- Fixed Sync so a malformed item no longer prevents the rest of a batch from syncing.

- Added support in Sync for Macs where you use different user names, so plugin icons and files from agents' workspaces in a synced chat still show on the other Mac.
- Fixed synced chats so they appear in the chat list right away in their place by time, without reopening the window.
- Fixed an open chat so messages added, edited, or deleted on your other Mac show up in it as soon as they sync, without closing and reopening the chat.
- Added Projects to Sync, so a chat stays in its Project on your other Macs, a Project you create, rename, or delete on one Mac does the same on the others, and Projects two Macs each made for the same folder become one.
- Added the pictures and files shown in your chats, such as charts agents make and screenshots, to Sync, so they appear in the synced chat on your other Macs too, while files over 16 MB stay on the Mac that made them.
- Added automatic cleanup of synced pictures and files a day after no chat shows them anymore, so deleted chats free space in your account, and Sync settings now says how many pictures and files are waiting for room.
- Added settings to Sync, so the models, prompts, and other preferences you change on one Mac reach your other Macs, while API keys, sign-ins, hotkeys, folder paths, and IM channels stay on each Mac, a setting you never changed on a Mac you add never replaces one you chose on another, and a setting that uses a plugin you haven't installed on a Mac applies there once you install it.
- Added your own AI commands, agents, and website commands to Sync, so one you create, edit, or delete on one Mac does the same on your other Macs, while model providers and API keys you add stay on each Mac.
- Added agents' character, identity, and tool choices to Sync, so an edit you make to an agent on one Mac reaches your other Macs, while the files and sessions the agent works on stay on each Mac.
- Added your workflows to Sync, so a workflow you create, edit, or delete on one Mac does the same on your other Macs, and when two Macs each had a different workflow with the same name, both are kept.
- Added your skills to Sync, so a skill you install, write, edit, or delete on one Mac does the same on your other Macs, a workflow or skill deleted on another Mac goes to the Trash so you can get it back, and skills over 4 MB stay on the Mac that has them.
- Added skills' on and off switches to Sync, so a skill you turn off on one Mac is turned off on your other Macs too, and turning it back on follows the same way.
- Added large store and GitHub skills to Sync, so a skill too big to copy is installed on your other Macs from where it came from, in the background, with Sync settings showing how many are still installing.

- Added knowledge bases to Sync, so the knowledge bases you create, with their notes, pasted text, web pages, and YouTube videos, appear on your other Macs and are searchable there, while imported files and recordings stay on each Mac.
- Added Memory to Sync, so what your agents remember on one Mac, and a Memory you edit or delete, is the same on your other Macs, while files you save to Memory stay on each Mac.
- Added a storage bar to Sync settings that shows how much of your account's sync space is used, turning amber once pictures and files start waiting for room.
- Added a Remove button to the computers listed in Sync settings, so a Mac you sold or set up again no longer stays in the list.
- Fixed Sync taking up to 30 minutes to start again after you sign back in to Enconvo or your Mac reconnects to the internet; it now resumes within a minute.
- Fixed settings synced from your other Mac, such as a command's model or a renamed command, so open windows show them right away instead of after you reopen them.
- Fixed Sync permanently skipping chats, settings, and knowledge that arrived while your Mac's disk was full; it now keeps them, says the disk is full in Sync settings, and finishes once there is free space.
