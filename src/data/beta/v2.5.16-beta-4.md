# Enconvo 2.5.16 Beta 4

Thanks for testing Enconvo 2.5.16 Beta 4. This build brings a new Today page and Ask Mavis to Email, an Auto web search that uses your chat model's own search, task models that stop background work from spending Cloud points on your own API key, inline Read Aloud, Enhance prompt, and a calmer Chat Window sidebar.

## Highlights

- **Email Today**: everything that needs you today in five tiers, each mail with a reason and one next step, worked through mail by mail.
- **Ask Mavis in Email**: ask about the open conversation and its attachments, then use the answer as a draft or carry it into chat.
- **Auto web search**: searches with the chat model's own web search and falls back to Enconvo Cloud, which is now free for every signed-in account.
- **Task models**: chat titles, suggestions, recordings and Live Talk run on a small model of the chat's own provider, so your own API key no longer spends Cloud points.
- **Read Aloud right in the reply**, with the sentence being read highlighted.
- **Enhance prompt**: the wand beside the mic rewrites your request into a clearer one, with Undo.

## Email

- Added Today to Email, the page it now opens on in place of Brief: an overview of how much needs you today with the most urgent senders and each mailbox's count, then five tiers from Urgent · must reply, Due today, Waiting on others (amber after 3 days) and Worth a look down to Later, where newsletters and notifications fold into one row you can archive all at once and undo.
- Added a reason and one next step to every mail on Email's Today (Draft Reply, Review Draft, Open or Nudge, plus Snooze and Archive), and opening one lets you go through that tier mail by mail with Previous, Next and a count of how many are done, moving on by itself after you send, archive or snooze.
- Changed how Email sorts mail for Today: rules sort what they can at once (a question from outside waiting a day, replies you are waiting on, notifications and promotions), and the model reads each new mail only once, also picking up a deadline from its text for Due today.
- Added Ask Mavis to an open Email conversation: the button (or ⌘J) opens a panel beside the mail where you ask about it and follow up, with answers that name the mails and attachments they come from, kept with the conversation for next time, and following you to the next mail you open.
- Added Use as Draft and Continue in Chat to Ask Mavis answers: Use as Draft writes a reply into the reply field marked Draft from Mavis · not sent for you to check and send yourself, and Continue in Chat carries the questions and answers into the chat beside Email.
- Added attachments to Ask Mavis in Email: attach files and images by picking, dragging or pasting them, or a Screen Doodle, and Mavis answers from them with the mail; they stay with the question and go along on Continue in Chat.
- Changed the Email conversation toolbar to Ask Mavis, Archive and a More menu that holds Flag, Snooze, Mark as Unread, Reply All, Forward, Move, Junk and Delete.
- Changed each mail in an Email conversation to show a full header like Gmail's: the sender's name with their whole address, the full date and time it was sent, and whom it went to and was copied to, with long recipient lists folded behind a +N more you can open.
- Changed Email's reading view to show the subject at the top of the conversation, moving into the top bar as you scroll, with a one-line Summary until it is summarized and icons that say what Ask Mavis, Summary, Draft a Reply and Suggest Replies do instead of sparkles.
- Fixed the Email reply field reading like a question to the AI: it now says "Reply to <name>…" (or "Reply to everyone…") and its button says Send, so it's clear the text goes to the person who wrote, and Write a Reply is now Draft a Reply, the AI's own button.
- Changed the Email plugin so agents can read a mailbox as soon as it is connected, including mailboxes added before; turn off Let agents read this mailbox on its Accounts page to keep agents out.
- Fixed pictures pasted into a mail showing as an empty box in an Agentic Inbox mailbox in Email; they now show in the mail, including in mail that arrived before this fix.

## Web Search and Models

- Added an Auto web search provider that searches with the chat model's own web search (OpenAI, Claude, Gemini, Grok, DeepSeek, Qwen, Kimi, Z.ai and OpenRouter), using the key or sign-in you connected for that model, and falls back to Enconvo Cloud or a provider you choose when the model has none or it fails.
- Added a search route preview to Settings › Web Search › Auto that shows which search the current chat model uses and when the fallback takes over, and web search steps in chat now say which search answered and why Auto fell back.
- Changed web search on Enconvo Cloud (Enconvo Cloud and DeepSeek Enconvo Cloud) to be free for every signed-in account, so searches no longer use your Cloud points, and the search provider settings now mark them as free.
- Fixed GPT replies signed in with a ChatGPT account losing the source links their web searches cited.
- Added Task models to Settings › AI Model, to choose the model for chat titles, next-message suggestions, recording titles and summaries, recording translation and idea titles, or turn next-message suggestions off.
- Changed chat titles to be written by a small model of the chat's own provider instead of the default provider's, so a chat on your own API key no longer spends Enconvo Cloud points naming itself.
- Changed next-message suggestions to run on a small model of the chat's own provider (DeepSeek V4.1 Flash on Enconvo Cloud and OpenRouter, GPT-6 Luna on OpenAI, Haiku on Anthropic), so a chat on your own API key no longer spends Enconvo Cloud points on them.

## Live Talk and Voice

- Changed Live Talk and Voice Command to talk on a fast model of the chat's own provider by default (Same as the Chat), so a call in a chat on your own API key no longer spends Enconvo Cloud points; Enconvo Fast is used only when the chat runs on Enconvo Cloud, and Live Talk's model can also be set in Settings › AI Model › Task models.
- Changed work handed to your Agent during a call to run on the model picked for that chat instead of the Agent's default model.
- Fixed Live Talk on the Mac not hearing you with some headsets and audio devices, where the microphone indicator kept flickering and the call ended with "The audio device changed": the call now ignores the changes its own microphone causes, goes on without Apple's echo cancellation when a device keeps switching under it, still moves to a microphone or speakers you switch to mid-call, and if a device truly keeps restarting, names it so you know which one to change.
- Changed Read Aloud under a chat reply to read right in the conversation instead of opening a separate player window: the speaker button turns into a small player with pause, resume and stop, the sentence being read is highlighted in the reply, only one reply reads at a time, and closing the chat stops it.
- Fixed turning on the speaker button (read replies aloud) in the Smart Bar also reading replies aloud in the Chat Window: each window now keeps its own setting, so the Smart Bar, the Dynamic Island and the App Sidebar read aloud only when their own button is on, and the Chat Window no longer reads replies aloud because of another window's button.

## Chat Window

- Added Enhance prompt to the Chat Window's message box: once you type a request, the wand beside the mic rewrites it into a clearer, fuller request on the chat's own model, using the conversation so far, and leaves [placeholders] for details only you know; Undo (or ⌘Z) puts your words back and Try again rewrites them once more.
- Added batch actions to the Chat Window sidebar: after picking chats with ⌘-click, Shift-click or a row's Select, a bar marks them as read, archives them or deletes them (with a confirmation that lists them, stops the ones still running and offers Archive Instead), with E, ⌫ and ⇧⌘U as shortcuts, ⌘A to pick a whole group, and Undo for read and archive.
- Fixed finished chats piling up in the Chat Window sidebar's Active chats: a chat whose reply arrived while the window was closed now leaves Active once you come back to it, and Active chats has a Mark all as read button on hover, while ⌘-click and Shift-click now pick several Active rows to mark as read or archive at once.
- Changed rows in the Chat Window sidebar's Active chats to work like the chat list's rows, with the same Pin and Archive hover buttons, right-click menu, double-click to rename and trackpad swipe to archive.
- Changed the Devices menu at the foot of the Chat Window sidebar to a cleaner list: Manage sits beside the title, the open-in-window and more buttons show only on the row you point at, keyboard shortcuts no longer show, and before anything is paired it shows a simple picture with Pair a computer and Pair a phone.
- Changed the Chat Window sidebar to drop the Connections entry, since devices are managed from the Devices button above Settings, which now shows as selected while Connections is open.
- Changed Memory to live inside the Knowledge Base in the Chat Window: a Knowledge Base / Memory switch sits at the top of its column, Memory no longer shows as one of your knowledge bases, and its separate sidebar entry is gone, with links to it opening the Knowledge Base on Memory.
- Changed the Artifacts library to list documents, slides, designs, motions, dashboards and web pages only; images, videos and audio now live in Media.
- Removed Workflows from Media, which lists only Images, Videos and Audio now.
- Changed the name of Film to Motion to tell it apart from AI-generated video.
- Changed the Chat Window sidebar's Scheduled icon to a calendar with a clock, so Scheduled no longer looks like History, and made section titles such as Pinned, Projects and Chats smaller labels set out from the rows under them.
- Changed Spaces such as Email to drop the title bar above the page while the sidebar shows the Space's name and navigation; it comes back when the sidebar is folded.
- Changed Spaces such as Email to put their top bar level with the window's buttons, where an empty part drags the window, and, with the sidebar folded, to name where you are beside the window's buttons in a menu that switches folders or shows the sidebar again; every Email page, from Subscriptions and Automation to Accounts, Add Mailbox, New Message and Templates, now names itself in that bar instead of a heading on the page.
- Fixed folding the Chat Window sidebar on a Space such as Email, which drew the Space's own sidebar in the page instead of hiding the navigation.
- Fixed the Email icon in the Chat Window's sidebar and on the phones looking larger than the icons beside it.
- Fixed tooltips such as All places on the Chat Window's icon rail staying up over the sidebar after a menu opened from them closed.
- Changed Create a space and New space on the Mac, iPhone and Android to open a chat outside any Project with "Create a Space that " ready to finish instead of attaching the plugin-development skill; the Agent now knows on its own that a Space is a plugin it builds.
- Added suggestions after "Create a Space that " in the Chat Window, shown dimmed after the cursor (such as tracking your subscriptions or your Claude and OpenAI API costs), which Tab or the right arrow fills in and typing narrows down.
- Changed the Plugins page's Spaces tab so New space starts the same chat as Create a space, from the Chat Window or from Settings.
- Fixed Live Screen staying on in the Chat Window with no way to turn it off there: while it is on, a Live Screen chip in the composer shows it and turns it off with a click, and it follows Live Screen turned on or off in the Dynamic Island.
- Changed Live Screen to belong to the window you turn it on in: turning it on in the Dynamic Island, the Smart Bar or the Chat Window no longer reaches the other windows, and the Chat Window composer now has its own Live Screen button to turn it on there.
- Changed the Chat Window composer to show Screen Doodle as its own button after Permissions and Live Screen, as the Dynamic Island does, instead of an item in the + menu.
- Fixed the first message of a new chat leaving its pictures and files in the message box after it was sent.
- Changed the chat input's `@` menu to close when nothing matches, instead of standing over the text with an empty "No matching items" list.
- Changed the `@` menu to stop searching once a query matched nothing, so typing on an email address or a long word no longer searches with every keystroke.
- Fixed Enconvo windows showing a bare "404: This page could not be found" page: a missing page now says This page isn't available, with Go Back when the page before is Enconvo's own, and the hidden Install MCP command that always opened one is gone.
- Changed what a window shows when part of it can't be drawn: only the chat's messages give way to a quiet Couldn't show this chat with Reload Chat, while the chat list and the composer keep working, and Reload Window comes up if it happens again, instead of a web-style error page whose Back left the window stuck.
- Fixed the Chat Window turning into a "This page couldn't load" page when an agent proposed a work plan.

## Agents and Subagents

- Fixed your Agent opening a separate chat when you asked Codex, Claude Code or another of your Agents to review or test the current work: in a Project it now starts that Agent as a Subagent and brings the result back to the same chat, and opens a separate chat only for new work such as a new feature.
- Added a reasoning effort choice to Subagents, teammates and parallel chats alike: a Work plan task can now set how hard its model thinks, with or without picking a model, and can go to any of your Agents or Coding agents as a teammate without making it a Project member.
- Changed how your Agent picks a model for Subagents: quick lookups, reading and simple repeated work run on your provider's small model (Haiku on Anthropic, GPT-6 Luna on OpenAI, Gemini 4 Hydrogen on Gemini, DeepSeek V4.1 Flash on Enconvo Cloud and other providers that offer it, otherwise the model you picked), harder reasoning gets a higher effort, and everything else stays on the model you picked; read-only Explorer Subagents on Enconvo Cloud now run on DeepSeek V4.1 Flash.
- Changed Subagents and teammate tasks that only make designs, docs, slides or other artifacts, research or review to work without a git worktree of their own, so starting several at once no longer copies the project for each.
- Changed Agent Script's name to Code Mode, with its settings under Settings › Agents and on the Plugins page's Built-in tab in a Code group.
- Fixed Computer Use reshuffling the desktop when it worked in a minimized window: instead of adding a hidden display and moving the window onto it, which reset Spaces and the menu bar like a display being plugged in, it now restores the window from the Dock and keeps out of your way: on a display you are not using when you have several, otherwise behind the app you are in, and leaves it open.

- Changed the iPhone voice call in the Dynamic Island and on the Lock Screen to a simpler look: the Enconvo logo without a status dot, the clock over the name, and round Share Screen, Mute and End buttons, while the Action Button choice shows only Voice only and Share Screen.
- Fixed Remote Screen on iPhone staying black in the app while Picture in Picture showed the computer's screen.
- Removed the Video Conference button from the top of Home on iPhone; open Video Conference from the sidebar or Settings.

- Changed file cards in a chat on the iPhone and Android apps to show only Open, without the Mac's Open in default app and Open in folder options.
