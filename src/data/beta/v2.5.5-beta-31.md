# Enconvo 2.5.5 Beta 31

Thanks for testing Enconvo 2.5.5 Beta 31. This build updates the official
DeepSeek lineup with a faster multimodal option and a cleaner model picker.

## Highlights

- **DeepSeek V4.1 Flash is now available** through your own DeepSeek API key or
  Enconvo Cloud, with image understanding, a 1M-token context window, tool use,
  and improved pricing.
- **The official DeepSeek model picker is easier to navigate** with the current
  Flash and V4 Pro models replacing retired and experimental entries.
- **Reasoning can be tuned for each task** with Disabled, Low, High, and Max
  options on both supported DeepSeek models.

## DeepSeek

- Added image input support to DeepSeek V4.1 Flash.
- Changed the default DeepSeek model to V4.1 Flash.
- Removed retired DeepSeek Flash and experimental vision model entries from the
  official model list.
- Added a clear prompt to refresh and choose a supported model when a saved
  selection is no longer available.
