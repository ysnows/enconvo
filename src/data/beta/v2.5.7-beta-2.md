# Enconvo 2.5.7 Beta 2

Thanks for testing Enconvo 2.5.7 Beta 2. This build lets Agents decide how to run each message, moves voice calls onto Enconvo Voice, brings Claude Code chats closer to its terminal on the Mac and iPhone, and adds about 300 Connectors.

## Highlights

- **Auto is the new run mode for Agents**: quick questions get a fast direct reply, tasks run as an Agent, and Auto Route picks the model for each kind of work.
- **Claude Haiku 5.5** arrives and becomes the default model for Enconvo Cloud and the Anthropic provider.
- **Voice calls run on Enconvo Voice**: Soniox hears you, an expressive ElevenLabs v4 voice answers, and greetings, replies and tasks start sooner on the Mac and iPhone.
- **Claude Code chats feel like its terminal**, with a plan card, bash mode, background tasks, Fast mode, shell output and diffs, clickable file references, and most of it on the iPhone Companion too.
- **A redesigned AI Commands page and PopBar**: describe a new command, try it on your own text, customize the built-ins, and run any command from the PopBar's Ask panel; Translator now follows your Response Language.
- **Read Aloud plays on the Dynamic Island** one sentence at a time, and an open Avatar reads aloud in her own voice.
- **About 300 new Connectors**, plus Claude Code plugin commands, agents and dependencies.
- **Firefox and Safari support** in the browser extension, with Ask Enconvo for Gmail, Google Docs, Calendar and more sites, and video and audio downloads.
- **Windows and Linux catch up** with live editing of Word, PowerPoint and Excel on Windows, Screen Doodle, Appshots, the Dictation bar, and KDE Plasma and GNOME on Wayland.
- **Team Seats** now go to each teammate's own account.
