# Enconvo 2.5.6 Beta 9

Thanks for testing Enconvo 2.5.6 Beta 9. This build brings more languages,
interactive plugin apps, easier workflows and scheduling, and lower-cost agent
tasks. Please try these changes in your everyday work and share any issues.

## Highlights

- Added ten interface languages on Mac, with instant switching and a Follow System option.
- Added interactive MCP Apps in chat and the sidebar, including tools such as the Bits & Bolts Parts Library.
- Changed Workflows to include a docked AI Assistant, reusable templates, clearer step settings, and help fixing failed runs.
- Added setting up scheduled tasks and workflows through chat, with results, notifications, and quick edits in the Scheduled view.
- Changed long agent tasks to reuse the prompt cache more reliably and show a clearer breakdown of conversation costs.
- Added ElevenLabs text-to-speech through Enconvo Cloud without a personal API key.

## Feedback

- Added an Enconvo feedback website with a search-first home page, roadmap overview, light and dark themes, and a duplicate check before posting, for feature requests, issue reports, voting, comments, and a public roadmap, with configurable Discord forum synchronization that also follows edits and deletions of Discord replies.
- Added Feedback links to the chat window's Help menu, the menu bar menu, Settings on Mac, and Settings on iPhone, which open the Enconvo feedback website.

## Chat and Attachments
