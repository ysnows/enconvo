# Enconvo 2.5.6 Beta 1

Thanks for testing Enconvo 2.5.6 Beta 1. This build brings more flexible Agent
skills, clearer recording recovery, and fixes for everyday voice and chat tasks.

## Highlights

- **Choose skills for each Agent** with a dedicated manager for shared and
  workspace skills, quick switches, and folder imports.
- **Keep reading your recordings while processing finishes** with saved
  transcripts, clearer errors, and retries for failed steps.
- **GLM-5.3 and GLM-5.3 Flash are now available** through your own Z.AI API key
  or Enconvo Cloud.

## Agent Skills

- Added support for workspace skills from Enconvo, Agents, Claude, and Codex
  folders, with independent skill selections for each Agent.
- Changed skill switches to save without refreshing the manager or losing
  your selection and scroll position.
- Fixed deleting linked skill folders while keeping their original files safe.
- Changed Agent deletion to preserve working-folder files and shared skills.

## Recording and Voice

- Fixed recording and live-caption transcripts getting stuck in Processing,
  with saved text available even when a later step fails.
- Changed the default Dictation model to Soniox Realtime v5 and Recording to
  Soniox Async v5 through Enconvo Cloud, while preserving saved choices.
- Fixed startup switching Dictation and Recording models or overwriting
  independently saved speech settings.

## Fixes

- Fixed Claude agent conversations stopping with JSON parsing errors when
  generating multiline tool inputs.
- Fixed Silent Screenshot OCR opening Dynamic Island instead of capturing a
  screen area and copying the recognized text.
