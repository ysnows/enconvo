# Enconvo 2.5.16 Beta 3

Thanks for testing Enconvo 2.5.16 Beta 3. This build brings Agent Script and one Skills library that learns from how you do things, a new Chat Window sidebar with an icon rail you can customize, faster design canvases and decks that update only what changed, and a lighter Remote Screen.

## Highlights

- **Agent Script**: the agent writes one short script that makes many tool calls side by side or in order and reads back only the result.
- **One Skills library**: every saved Workflow is also a Skill, run the cheap way first, repaired from its own notes, and taught by your corrections.
- **A new Chat Window sidebar**: a slim icon rail beside the chat list, a middle column that follows it, Customize sidebar, a count of chats that need you, and ⌥⌘ shortcuts.
- **Design canvases and decks that update in place**: a small change redraws only the part it touches, and the agent draws artboards and writes slides in parallel.
- **Remote Screen shows the Mac's own cursor**, and frames appear as soon as they arrive.
- **Drafts kept per chat**: switch to another chat and come back to find your text and attachments as you left them.

## Skills and Agent Script

- Added Agent Script: the agent can write one short script that makes many tool calls side by side or in order and reads back only the result, with its own settings under Settings › Plugins › Agent Script.
- Changed Agent Script runs outside a chat to call only tools that read: built-in searches and reads, public web pages, ordinary files, and MCP tools that don't say they change anything, checked again right before each call.
- Added one Skills library: every saved Workflow is now also a Skill with its own SKILL.md, and Settings › Skills shows your own Skills by where they came from (recorded, learned, script, written) with their steps, gotchas and full history.
- Added running a Skill the cheap way first: its saved steps run without the main model, a step that no longer fits is repaired from the Skill's own notes and screenshots, and only when that fails does an agent do the task from SKILL.md.
- Added Learn how-tos (Settings › Memory): when you correct how a task was done, or a step had to be repaired, the Skill learns it at once and the chat shows a Learned note with Undo; a task done a second time becomes a new Skill, and Memory Review and Memory Tidy look after Skills too.
- Added an option to approve step changes first: with Ask me first, a learned change to a Skill's steps waits for Apply on its note, while gotchas still go in at once.
- Added Workflow script steps, so a Skill can keep an Agent Script in its own scripts folder and run it as one of its steps.
- Added turning a recording into a Skill: each recorded action becomes a checked step, with its screenshot kept for repairs, and the Skill stays a draft until a run of it works.

## Chat Window Sidebar

- Changed the Chat Window sidebar: its places moved to a slim icon rail left of the chat list, with Chats first and an amber count of the chats that need you, then Scheduled, Knowledge Base and Plugins (Board, Artifacts, Memory and the rest wait in the ··· menu), your plugins below a line, and your device and Settings at the foot.
- Added Customize sidebar: pick which places show on the icon rail and drag them into your order (from the ··· menu or by right-clicking an icon), drag a plugin above the line to sit among the places or back below it, press Create a space under your plugins for a new chat that starts with the plugin-development skill and “Build a Space that”, pin or unpin any place or plugin from the ··· menu, and open what the rail shows with ⌥⌘1 to ⌥⌘9.
- Changed the Chat Window's middle column to follow the icon rail: Board, Artifacts, Knowledge Base, Memory, Scheduled, Media, Workflows, Plugins and the Email plugin each show their own sections, filters and main action there, Skills and MCP servers open right in the window from Plugins, Connections and Video Conference take the full width, and Chats comes back where you left it.
- Changed the Chat Window's Back and Forward to remember the places you visited and the section you picked in each, with a list of them when you hold Back, and ⌘B now hides only the middle column and keeps the icon rail.
- Fixed the Chat Window sidebar jumping when you fold a long section near the end of the list: the section header now stays under the pointer.
- Changed the message box to keep each chat's unsent text and attachments while you look at another chat, so switching back finds your draft as you left it.
- Changed the message box's Vim Mode indicator into a mode chip beside the microphone that turns blue in Normal and Visual mode and shows a command still being typed.
- Added automatic input source switching to Vim Mode on the Mac: Normal and Visual mode type with an English keyboard layout, and Insert mode brings back the input source you were using, such as Pinyin.

## Design Canvases and Decks

- Changed design canvases so a small change such as an icon, a color or a line of text updates only that part, and only the artboards it touches redraw instead of the whole canvas.
- Changed design, deck, film and dashboard editing so the agent changes just the part you ask about instead of rewriting the whole page or slide.
- Added parallel drawing on design canvases: when a canvas has several artboards, the agent can draw them at the same time and you watch each one appear side by side.
- Added parallel slide writing: for longer decks the agent writes several slides at the same time, and each one shows in the panel as it is ready.
- Changed the deck panel so when only some slides change, just those slides update on the stage and in the thumbnails instead of the whole deck reloading.
- Changed the deck panel so slides the agent adds, removes or reorders appear in place on the stage and in the thumbnails, keeping the slide you are on, and slides you duplicate, delete or drag to a new place change in place too, with duplicating taking you to the copy.
- Fixed slide and design exports and the deck layout check failing on the Mac with "hasn't finished drawing the export".
- Fixed thumbnails squashed to a thin strip in the deck panel after the agent changed those slides.

## Remote Screen and Phones

- Changed Remote Screen on the phone to show the Mac's own cursor in the picture instead of drawing a large cursor and halo over it, so the cursor no longer covers what you type.
- Changed Remote Screen to show each frame as soon as it arrives instead of buffering it for smoother playback, so the picture and the cursor in it follow your finger more closely.
- Changed the iPhone message box to match Android: plus, the text, the microphone and the call or Send button sit on one row (Mac chats included), plus and the microphone fold away while you type or attach so only Send is left, and a Skills chip sits over the box in Mac chats.
- Fixed the computer chip on the iPhone home screen getting cut short when a project is chosen: the chips over the box now scroll sideways.
- Changed the Side Panel button on the iPhone and Android to a cleaner icon, a rounded window with its side panel shaded.
- Changed a new chat on another computer to hide the Side Panel button until its first message is sent, as in the Chat Window.
- Fixed a large photo taken with the phone held upright reaching the model lying on its side.

## Linux Servers

- Added Settings in your browser for a Linux server added over SSH: turn it on while installing Enconvo there (on by default) or later from the server's page, then Open shows that server's own models, agents and plugins in your Mac's browser through an SSH tunnel, and Manage in a server window's model menu opens them too.
- Added a question to `enconvo service install` on a Linux server whether to open Settings in a browser, which then answers on 127.0.0.1:54580 and prints the SSH tunnel to reach it from your own computer, and `enconvo companion pair` typed on a server now says where to change that server's own models, agents and plugins.

## Calls

- Changed Conference's Take notes setting (now Take notes on my calls) to start notes in every call you answer or join, not only the ones you start, so a call someone else opened is transcribed and summarized too.

## Speed, Files and Safety

- Fixed a slowdown on Mac while several chats were working, where copying files in Finder and other apps waited behind the commands and image jobs agents were running: that work now gives way to your own apps.
- Changed how a large image is prepared for the model on Mac, so a big screenshot or photo is ready in a fraction of a second instead of several seconds and takes less to upload on every turn.
- Fixed Files compressing, converting or resizing the same images and PDFs again when asked a second time: a file already done with the same settings is kept as it is and marked Already done, instead of being written as a second copy.
- Fixed deleting a chat leaving the pictures and files you had pasted or attached to it on disk, which kept growing; they now go with the chat, and ones another chat still shows stay.
- Fixed agent commands that waited for typed input nobody could give, such as a grep that got no file: they now end at once instead of staying in the chat's background tasks as running until stopped.
- Fixed Approve for me not asking before an agent read a saved password or token file through another file tool, a path relative to a folder the agent named, an escaped file:// link, the Data volume's path, a link, or a folder search with a name filter.
- Fixed Web Fetch so a public page can no longer redirect a request to this Mac or its local network, including a page's price lookup.
