# Enconvo 2.5.6 Beta 12

Thanks for testing Enconvo 2.5.6 Beta 12. This build brings clearer AI usage
statistics, more ways to save and share useful conversations, and improvements
to Sync, Memory, and everyday agent tasks.

## Highlights

- **See where your AI usage goes**: track estimated cost, tokens, cache savings,
  and response speed across providers, with quick access from provider settings.
- **Keep API keys in sync across your Macs** with optional, passphrase-encrypted
  sync that is off by default.
- **Share a conversation and keep it going**: create public or password-protected
  chat links, export Markdown, and continue a shared chat in Enconvo.
- **Get more from saved posts and videos** with readable post views, video
  transcripts, and Ask AI citations that take you to the relevant passage or
  moment.
- **Build workflows more easily** with a searchable step palette, clearer run
  results, and a redesigned list and details view.
- **More dependable everyday assistance** with better Memory recall, quicker
  Computer Use and Browser Use, and smoother Quick Memory and voice notes.

## Usage Statistics

- Added a Usage Statistics page in Settings that shows estimated cost, tokens, requests, cache hits and response speed for every AI provider Enconvo calls, including chat models, speech, images, video, web search, document parsing and embeddings, with per-model details and a request log.
- Fixed Usage Statistics counting cache reads and writes from older usage as input cost, so their cost breakdown and cache savings now show.
- Fixed the Usage Statistics chart drawing a small model's colored outline along the top of the whole chart.
- Added a usage button to the top of each AI provider's settings that shows the last 30 days of cost for that kind of provider, such as all chat models, with a hover overview of requests, tokens, cache hits and daily trend, and opens Usage Statistics scoped to it.
- Added a footer to the model picker that shows which account or API key the highlighted provider uses and how it is paid for, such as Enconvo Cloud with your points, a signed-in subscription, your own API key or a local server, and opens that provider's settings in one click.

## Sync

- Fixed changes from your other Macs taking a minute and a half or more to arrive for up to half an hour after your Mac came back online from a long time offline.
- Fixed changes from your other Macs sometimes taking more than half a minute to arrive right after the sync service briefly restarted for an update.
- Changed Sync so new chats keep syncing when your sync storage is full, by dropping the oldest synced chats from your account while every Mac that already has them keeps them.
- Fixed a Mac sometimes failing to download a sync account that holds many large chats or knowledge bases.
- Changed the What syncs list in Sync settings to show Settings first, above Chats and Knowledge Bases.
- Added API key sync to Sync settings, off by default, which keeps your built-in providers' API keys the same on your Macs, encrypted with a sync passphrase so only your Macs can read them.

## Memory
