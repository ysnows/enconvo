# Enconvo 2.5.7 Beta 1

Thanks for testing Enconvo 2.5.7 Beta 1. This build brings Claude Code into the Chat Window, Ask Enconvo to the browser extension and a much faster Live Talk, and brings most of the Mac's everyday tools to Windows and Linux. Please try the areas below and send feedback from the app.

## Highlights

- **Claude Code runs in the Chat Window**, in any folder you pick, with its tool calls, file changes, subagents, plan and usage limits shown as it works, and terminal sessions you can continue in Enconvo.
- **Ask Enconvo in the browser extension** chats about the page, post, video or thread you're on, with its comments and replies, on X, Reddit, YouTube, Bilibili, GitHub, Stack Overflow, Wikipedia and more.
- **Live Talk answers sooner**: calls connect faster, simple questions are answered by the voice itself, and tasks handed to the Agent come back several seconds sooner.
- **Windows and Linux catch up** with Computer Use, Clipboard History, Dictation, Quick Capture, Window Management, Live Screen and offline ONNX models.
- **A lighter, faster SmartBar** that shows results sooner, redraws far less and follows the app language throughout.
- **Eighteen built-in Avatar characters**, including six Enconvo plush originals, on the Mac and iPhone with nothing to download.
- **Codex and Claude Code plugins** install from GitHub, npm, folders or marketplaces, and the `enconvo plugin` CLI validates, packs and publishes them.
- **A one-time 7-day Plus trial** for Free accounts, with no card needed.
