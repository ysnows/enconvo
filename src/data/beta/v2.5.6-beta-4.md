# Enconvo 2.5.6 Beta 4

Thanks for testing Enconvo 2.5.6 Beta 4. This build shows what each chat costs
in Enconvo Cloud points and keeps long agent runs in check. It also speeds up
multi-step agent tasks and brings the Mac's Avatars, full-screen voice chats,
and settings sync to the iPhone app.

## Highlights

- **See what each chat costs.** A points pill next to the chat window's model
  picker shows tokens, estimated points, prompt cache hits, and what fills each
  request.
- **Enconvo Cloud spending stays in check.** Agent runs pause at 50,000 points
  to ask before spending more, and balances no longer go below zero.
- **Faster and cheaper agent runs.** Agent mode does independent steps together,
  and conversations with more than about 200 messages reuse the prompt cache
  again.
- **The Mac's Avatars on iPhone**, including Sarah, with lip sync, expressions,
  and a full-screen voice chat view.
- **Settings sync between Mac and iPhone** for the default chat model,
  read-aloud voice, image model, the main Agent's Avatar, and Auto Hang-Up.

## Enconvo Cloud Points

- Added a points pill next to the chat window's model picker that shows the
  tokens and estimated Enconvo Cloud points the conversation has used.
- Added Context and Usage tabs to the points pill. Context shows what filled the
  latest request, such as skills, MCP servers, tool results, and the
  conversation. Usage shows input, cache, and output tokens with points, totals
  by model, and the largest steps.
- Added the prompt cache hit rate to the points pill, colored green, amber, or
  red so a conversation that keeps missing the cache stands out.
- Added a Cloud Points Run Cap. An Enconvo Cloud agent run that reaches 50,000
  points without a final answer pauses and asks before spending more. You can
  set the cap to 25,000, 100,000, or 250,000 points, or turn it off.
- Added a warning after you switch to an Enconvo Cloud model that costs 5 or
  more times as much, with the estimated points per step and a Switch back
  button.
- Changed the model picker to tell you when a model you pick applies to that
  command only, with a Make Default button in the chat window.
- Fixed Enconvo Cloud balances going far below zero. New requests stop once your
  points run out, and each reply's cost comes off your balance right away.
- Fixed conversations with more than about 200 messages paying full price on
  almost every turn. They now reuse the model's prompt cache, which is up to 10x
  cheaper with GPT-6.
- Fixed Settings → Points usage and the Account balance showing old numbers.
- Fixed the out-of-points error to say that the command uses Enconvo Cloud and
  how to switch the default model in Settings → AI Model.

## Agents and Skills

- Changed Agent mode to do independent steps together, such as creating several
  folders or making several edits in an MCP app, so these tasks finish in a few
  seconds. A failed step no longer stops the others.
- Fixed stopping an agent run repeating the finished steps in the chat history or
  replacing the previous answer, which could make the next message fail with
  Claude models.
- Added Enable all and Disable all to the Skills page's … menu, with Undo.
- Fixed agents seeing the same skill several times when it is in more than one
  skills folder, such as `~/.claude/skills` and `~/.codex/skills`.

## iPhone Avatar and Voice Chats

- Added Sarah and the other Mac characters to iPhone Avatar settings, now a
  swipeable carousel of character covers with Download, Update, and Use on each
  card.
- Added the Mac's lip sync, facial expressions, pose blending, and idle stances
  to the iPhone avatar in voice chats and Read Aloud.
- Added the Mac's Avatar Instinct to iPhone voice chats, so the character reacts
  to the conversation and performs the moves a reply promises.
- Added Perform and Look to the avatar's hold menu, with each character's own
  motions and a look remembered per character.
- Added a full-screen avatar view with pinch to zoom, drag to turn the
  character, and a double-tap face close-up.
- Changed iPhone voice chats to open straight into the full-screen character,
  with call buttons down the right side, live captions, and a spoken greeting
  when the call connects.
- Added typing during a voice chat, and Auto Hang-Up for quiet calls, shared
  with the Mac's Realtime Voice setting.
- Changed text chats to no longer show the character above the conversation.
  Home shows it only when Show on Home is on in Avatar settings.
- Removed Cute Cat from iPhone Avatar settings.
- Fixed the iPhone avatar shrinking during big moves, looking blurry when a voice
  chat first opened it, and staying blank when a voice chat started from Home.

## iPhone Chats and Sync

- Added settings sync between the Mac and iPhone for the default chat model,
  read-aloud voice, image model, the main Agent's Avatar, and Auto Hang-Up. The
  device that changed a setting last wins.
- Added a Connect your Mac card to the iPhone home screen for pairing in one
  tap.
- Added a QR code and public TestFlight link to Settings → Connections for
  installing the iPhone app.
- Added date and time stamps between iPhone chat turns.
- Changed the iPhone chat screen to a finer look with thinner icons, a blue
  bubble for your messages, and a softer message box.
- Changed iPhone chat replies to stream more smoothly in long conversations.
- Changed iPhone dictation to start listening the moment you tap the mic.
- Changed iPhone Read Aloud to use xAI through Enconvo Cloud by default.
- Fixed iPhone chat replies failing with "The phone is offline" after switching
  networks or turning on a VPN.
- Fixed the Mac taking up to five minutes to reconnect to paired iPhones after
  Enconvo restarts.

## Fixes

- Fixed a long queued message in the chat window hiding the Steer button.
- Fixed a newly downloaded Avatar character showing as locked in other open
  Avatar windows until Enconvo was restarted.
