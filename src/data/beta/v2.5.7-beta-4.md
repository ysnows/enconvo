# Enconvo 2.5.7 Beta 4

Thanks for testing Enconvo 2.5.7 Beta 4. This build adds Fast mode to the model picker, makes Save to Knowledge Base on the PopBar quicker and smarter about links, and gives voice calls a much longer memory with more dependable handoffs to tasks.

## Highlights

- **Fast mode in the model picker**: supported OpenAI, Anthropic and Enconvo Cloud models get a ⚡ Fast chip that runs the model faster at a higher price.
- **Save to Knowledge Base on the PopBar**: one of the default buttons now, it shows its progress on the Dynamic Island and saves a selected link as the web page itself.
- **Voice calls remember much more**: a call keeps every turn until its context nears 100K tokens, and a request you type or ask about an earlier file or photo now reliably starts a task.

## Models

- Added Fast mode to the model picker: supported OpenAI, Anthropic and Enconvo Cloud models show a ⚡ Fast chip next to the reasoning levels that runs the model faster at a higher price (2x points on Cloud, or 6x for Ultrafast on GPT-6.1 Sol and GPT-6 Astra), saved per model, and a request the provider can't serve fast right now goes through at standard speed and price instead of failing.
- Fixed Enconvo Cloud models such as MiniMax M3 failing with a long raw Cloudflare 524 error when the provider's server stalls: Enconvo Cloud now tries the request once more, and if it fails again shows one short message naming the provider.

## Save to Knowledge Base

- Added Save to Knowledge Base to the PopBar's default buttons, right after Screen Doodle, so one click saves the selected text as a note, and the bar now shows 11 buttons so nothing moves into More.
- Changed Save to Knowledge Base on the PopBar to its own teal icon, lines of text filing into a stack like Read Aloud's waveform, and moved its knowledge base picker from the ▾ beside it into the button's right-click menu, on the vertical PopBar too.
- Changed Save to Knowledge Base on the PopBar to close the PopBar and show the save on the Dynamic Island: a pill under the notch while it saves, then where it went with Undo and Open, or what went wrong with Retry; a click outside folds it into the notch, where a small stack icon keeps showing progress and a check when it's done, and hovering it opens the pill again.
- Changed Save to Knowledge Base to save a selected link as the web page itself, fetched and searchable like Add Single Web Page (a YouTube link saves the video), instead of a note holding the link; a page that's already in that knowledge base stays as it is.
- Fixed Save to Knowledge Base showing a generic error when a save failed; it now says why, for example when a page couldn't be fetched.
- Added an Add to Knowledge Base button in browser Page Chat to save the selected page scope with its source link to a knowledge base of your choice.

## Voice Calls and Tasks

- Changed voice calls to remember much more of the conversation: a call now starts with far more of the chat and keeps every turn until its context nears 100K tokens, then clears older task details and photos, and only after that lets the earliest turns go.
- Fixed voice calls where Enconvo said it would have the assistant look something up, such as a clause in a contract you sent, but never started the task.
- Fixed Hub tasks not finding a file you sent earlier in the conversation, such as a contract, and searching the whole Mac for it instead; a task now reads the file you sent directly.
- Fixed long voice calls asking you to send a photo again when you asked about one shared much earlier in the call; Enconvo now has the photo looked at in the chat instead.
- Changed progress updates in voice calls to say what a task is doing right now, without counting its steps or reading out tool names and file paths.

## iPhone Companion

- Fixed starting a voice call on iPhone sometimes failing when the connection to the Mac dropped for a moment; the iPhone now tries once more on its own.
- Fixed a single photo in a Mac chat on iPhone showing cropped; it now shows whole.

## PopBar and Translator

- Changed Translate in the PopBar's small SmartBar to show its Source and Target Language pickers in the top bar, in place of the Inline Mode switch, instead of in a separate row below it; Translator's Inline Mode is still in its settings.

## Fixes

- Fixed a crash on macOS 27 when Computer Use read Enconvo's own windows, for example when an agent asked for the state of the frontmost app while Enconvo was in front.
- Fixed the Chat Window's chat history and Projects showing empty after an update until Enconvo was restarted; the lists now load as soon as Enconvo finishes starting up.
