# Enconvo 2.5.7 Beta 3

Thanks for testing Enconvo 2.5.7 Beta 3. This build adds PopBar extensions and a rebuilt PopBar, moves Translator into the Writing Toolkit, lets you label Screen Doodle drawings by voice, and brings Mac voice calls in line with the iPhone.

## Highlights

- **PopBar extensions**: install extensions in PopClip's format from Enconvo's reviewed catalog, a link, a file or your PopClip, and choose where their buttons go on the PopBar.
- **A rebuilt PopBar**: a searchable ⌄ More panel with Add Buttons…, New AI Command with your own instructions, icon and hotkey, new Screen Doodle and Sound Native buttons, and Reset to Default.
- **Translator joins the Writing Toolkit**, with its Source and Target Language pickers back and quick language pickers in the SmartBar and Screenshot Translate.
- **Spoken labels in Screen Doodle**: draw an arrow or shape and say what it points at to place a label beside it.
- **Mac voice calls work like the iPhone's**: your words appear as you speak, Doodle and Live Screen go straight to the call, quiet calls nap instead of hanging up, and calls carry on when you switch to AirPods.
- **Microphones and recordings**: second-channel microphones record your voice, meeting recordings keep going when the microphone changes, and Enconvo's sounds play fuller.
- **Jev is free**: Auto Route, Auto run mode, Memory, Avatar reactions and Operators no longer use Enconvo Cloud points.

## PopBar and AI Commands

- Changed the PopBar so buttons of the same kind share one frame, with Ask in Sidebar, Search, Copy and Open Link drawn as one set of icons, a green check after copying, and the link's site on Open Link.
- Changed the PopBar's ⌄ menu into a panel that opens from the bar like Ask AI, with a search field, then the buttons that don't fit on the bar and Customize and Show Less Often side by side, all in one list that scrolls together.
- Changed the PopBar's light appearance to a clear light glass with softly recessed button groups, so it looks clean on white pages.
- Changed the Ask AI panel on the PopBar so one highlight slides smoothly to whatever you point at, like the panel that opens from ⌄.
- Changed the PopBar's Ask in Sidebar, Search and Copy icons to be a little larger.
- Changed Ask AI on the PopBar to glow with a slow blue and violet flow while you point at it, which stays still when Reduce Motion is on.
- Fixed Edit Buttons on the PopBar so Ask AI, Read Aloud and other buttons that stand on their own can be dragged to a new place, and dragging a button past another group moves its whole group there.
- Changed Edit Buttons on the PopBar to also show the buttons in the ⌄ menu after a ⌄, so you can drag a button across it or use Move to the Bar and Move to the ⌄ Menu, and removing a button from the bar keeps the menu's buttons in the menu.
- Added Add Buttons… to the PopBar's ⌄ More panel, which lists the PopBar buttons, PopBar extension actions and AI Commands not yet on your PopBar, with search, so you can add several in a row, plus Get Extensions… and New AI Command… for one that isn't there.
- Added Reset to Default to the PopBar's ⌄ More menu once you've changed its buttons, with Undo.
- Added a Screen Doodle button for the PopBar, drawn as an arrow pointing at a hand-drawn circle, that opens Screen Doodle in one click; it takes Screenshot's place among the default buttons, right after Read Aloud (Polish Email moves into the ⌄ menu, also on a PopBar still set to the default buttons), and you can add it from the PopBar's button gallery.
- Added Sound Native to the Writing Toolkit, right after Fix Spelling on the PopBar, to rewrite your text so it reads the way a native speaker would write it, in the same language; Polish Email moves into the PopBar's ⌄ More panel, and PopBars you arranged yourself stay as they are.
- Changed New AI Command on the PopBar to work like the one in Settings, so you can write the instructions yourself, pick its icon from the same icon library and set a hotkey without leaving the PopBar.
- Changed New AI Command on the PopBar and in Settings to a roomier card where a draft opens in the same form as writing it yourself, so you can edit the instructions, try them on your text and refine them before saving, with Add to PopBar on by default.
- Fixed New AI Command on the PopBar and in Settings closing while a new command was still being saved, and the PopBar card getting stuck when you went back to describing it during a Redraft or a try.
- Fixed the PopBar in Microsoft Edge showing for an empty selection and a PopBar extension searching for a stray symbol; it now reads the text you selected on a web page.

## PopBar Extensions

- Added PopBar extensions, which use PopClip's extension format: browse Enconvo's reviewed catalog on the new PopBar Extensions tab of the Plugins page, add one from a link, a file or a snippet, or import yours from PopClip, add its actions to the PopBar from the Button Gallery, and see what an extension or its update can access before it installs.
- Added a PopBar Extensions page at app.enconvo.com/popbar-extensions to browse Enconvo's reviewed catalog and install an extension in Enconvo.
- Changed PopBar extensions to put the buttons they add at the front of the PopBar's ⌄ More menu, or on the bar while it has room, with a dot on ⌄ and a NEW badge until you open it.
- Changed a newly installed PopBar extension to put its buttons right after the last button your PopBar shows for selected text, such as Screen Doodle.
- Added PopBar buttons to a PopBar extension's page in Plugins and to the card after you install one, laid out like an AI Command's PopBar row: a switch per button that shows when it appears, and the live PopBar, where you can drag any button, move it into ⌄ More and out, change how it shows or take it off.
- Added Get PopBar Extensions to the PopBar settings page, which opens the PopBar Extensions tab in Plugins so you can find more buttons.
- Fixed PopBar extension actions that need another app, such as one for a particular editor, so when that app isn't on your Mac the PopBar says so and opens where to get it, instead of failing.
- Changed the card shown after you install a PopBar extension to be wider, so its live PopBar shows more of your buttons.
- Fixed the live PopBar on a PopBar extension's page, its install card and an AI Command's page responding slowly when you turn a button on or off, open a button's menu, scroll the bar or come back to the window.
- Changed the install card for a PopBar extension to show one quiet "Checking…" in the shape of the finished card while it checks the extension, instead of two spinners, so the card barely moves when the check ends.

## Translator

- Changed Translator and Screenshot Translate to live in the Writing Toolkit plugin and removed the separate Translate plugin, keeping your settings, hotkeys, PopBar and Dynamic Island buttons, your own copies of these commands and past translation chats.
- Removed the DeepL, Youdao, Caiyun and Translator (Interactive) commands; their past chats, pins and buttons now open Translator.
- Fixed Translator so you can again choose its Source and Target Language; it translates both ways between the two, text in any other language goes into the Target Language, and Auto uses the Response Language from My Profile, or the system language when that is Auto.
- Changed the AI Commands page to show a built-in command's full prompt, matching its plugin settings, with Translator's shorter instructions and searchable Source and Target Language pickers right below it.
- Changed the PopBar's Translate suggestion to name the language Translator will use, following its Target Language.
- Added quick Source and Target Language pickers to Translate in the PopBar's small SmartBar and to the Screenshot Translate answer below the notch; picking a language saves it to Translator and translates the same text again.
- Fixed Screenshot Translate on the Dynamic Island ignoring the model chosen for Translator, which could translate into the wrong language after you changed the Target Language; Translator now always translates into the Target Language unless the text is already in it.

## Screen Doodle

- Added spoken labels to Screen Doodle: after drawing an arrow or shape, hold the left Option key (or your Dictation hotkey) and speak to place a text label beside the middle of the arrow, on whichever side has room, or beside the shape, clear of any earlier labels, with a hint the first few times you draw.
- Added a Speak After Each Shape toggle to the Screen Doodle toolbar, on by default, that starts listening as soon as you finish an arrow, line, box, circle or number, or when you pause after a pen stroke, places the label when you pause, and shows a short guide beside the recording capsule the first few times.
- Added a Dictation-style recording capsule beside each Screen Doodle spoken label, so you can click ✓ to stop and place the label or ✕ to cancel it, which then draws in to a small pill with a light running through its bars while the words are finished.
- Changed Screen Doodle so any drawing tool can grab a text label and drag it to a new spot, without switching to Select.
- Fixed Screen Doodle leaving a tiny stray arrowhead or shape when you click with a drawing tool without dragging.
- Changed the Screen Doodle toolbar's ✓ button to a send button, so it is clear that it sends your doodle to the chat.
- Changed Screen Doodle on a selected region to show its toolbar right below the region, or above it when there's no room below, instead of at the top of the screen.

## Voice Calls and Avatar

- Changed Mac voice calls to always open with the Agent's greeting once connected, whether or not the Avatar is shown.
- Changed the Mac chat during a voice call to show your spoken words as they are heard, like the iPhone.
- Changed Doodle in a Mac voice call to send your drawing straight to the call, so the Agent looks at it and answers like a photo sent from the iPhone.
- Changed Live Screen in a Mac voice call to work like iPhone screen sharing: the Agent looks at your screen itself when your words need it and answers right away.
- Fixed the spoken line for turning on Live Screen or sharing your camera or screen in a voice call being skipped when the Agent was still talking; it now plays once the Agent finishes, unless you speak first.
- Added a Napping 💤 status to Mac voice calls, shown on the Dynamic Island when a quiet minute pauses listening, and your voice wakes the call again.
- Removed Auto Hang-Up from voice calls on the Mac and iPhone, including its setting, so a call no longer ends on its own after a quiet stretch; it naps until you speak again and stays connected until you hang up.
- Fixed Mac voice calls ending when you connect or disconnect AirPods or switch audio devices; the call now carries on through the new device.
- Fixed Mac voice calls so the first call, such as one started by double-clicking the Avatar, connects instead of failing to start audio on some headsets and audio devices.
- Fixed Mac voice calls not hearing you with echo cancellation on, for example through an external or wireless microphone, and echo cancellation now also starts with 48 kHz microphones, so the voice is less likely to hear itself.
- Fixed the voice in Mac voice calls sounding quiet and thin when the microphone and speakers belong to the same external device, such as a Studio Display; it now sounds as full as through other speakers, with echo still kept out.
- Changed voice calls so the voice knows it is speaking out loud: asked to read something, sing, whisper or send a voice message, it just says it, and it no longer claims it can only type.
- Fixed the opening greeting of a voice call sounding broken up between words; it is now spoken as one smooth sentence.
- Fixed voice calls so asking the voice to read a poem or passage aloud, tell a story or sing has it say the whole thing right away, instead of only saying it will or stopping halfway.
- Fixed iPhone voice calls taking longer and longer to answer as a call went on, up to several seconds after a quarter of an hour; replies now come as quickly late in a call as at its start.
- Fixed the Avatar on the Mac and iPhone striking poses, acting out a feeling or changing outfits in the middle of ordinary conversation; she now does so only when you ask her to.

## Dynamic Island

- Fixed the Read Aloud captions on the Dynamic Island rewrapping and shifting as the spoken words light up, so the sentence stays still while it is read.
- Fixed a screenshot taken from the Dynamic Island's shortcuts opening in the SmartBar; it now comes back to the Dynamic Island, attached to your next question.
- Changed the Dynamic Island's OCR result to say Copied to Clipboard once the recognized text is copied.
- Fixed the Dynamic Island closing when you cleared the text you had typed (for example with ⌥⌫ or ⌘⌫) while the pointer was away from it; it now stays open on the empty input so you can keep typing.
- Fixed the Dynamic Island sometimes turning into a black bar that no longer opens on hover after you open an app, run an action or copy a result from it; it now folds back to its pill instead of disappearing.
- Changed the Dynamic Island during a Mac voice call or a Voice Command reply to leave more room at both ends of the pill, around the wave and the hang-up or stop button.

## Dictation, Microphones and Meeting Recordings

- Fixed microphones that carry your voice on their second channel, such as a wireless receiver's second transmitter or an audio interface's second input, recording silence in Dictation, Voice Command, meeting recordings and Chat Window voice input.
- Fixed Chat Window voice input to use the microphone chosen for Voice Input, keep listening after a microphone is plugged in or out, and pick up less hiss.
- Fixed the start of a dictation sometimes repeating briefly and its last moment being cut off.
- Fixed meeting recordings going silent after the microphone changes, such as AirPods connecting or a USB microphone being unplugged; they now keep recording from the chosen microphone, or the system's while it is gone.
- Fixed meeting recordings crackling when your voice and the meeting's audio are loud at the same time.
- Fixed sounds and spoken replies played by Enconvo sounding thin, as they no longer have their low end cut.

## Models and AI Providers

- Changed Jev, the quick decision model behind Auto Route, Auto run mode, Memory, Avatar reactions and Operators, to be free, so it no longer uses Enconvo Cloud points.
- Fixed switching an AI provider such as Anthropic from Subscription to API Key not reaching Agents and existing chats that kept using the subscription, so the next message now uses the API key right away.
- Fixed subscription usage in AI provider settings showing the previous account's limits after reconnecting with another Claude account, and Refresh Usage now fetches the latest numbers, with a spinner on the account's ⋯ button while it refreshes.

## Browser Extension

- Fixed X Page Chat to read full posts and replies from the signed-in browser, including posts opened from the timeline, with clear limits when only part of the discussion is available.
- Fixed browser Page Chat so closing or dismissing its panel keeps the answer running in the background and reopening shows its progress or completed result.
- Changed browser extension panels in light appearance with clearer text, softer shadows, consistent input and button states, and page-aware colors for replies, chat, downloads and knowledge base menus.
- Fixed Reddit's Save and Ask buttons to match the native action bar's size, spacing and alignment.
- Added AI reply suggestions in Reddit comments, with editable previews, tone and length refinements, and saved reply instructions.

## iPhone Companion

- Changed the iPhone Companion to stop asking whether to allow AI data sharing before a voice call, chat or dictation; sharing is on unless you turn off Allow AI data sharing in Settings, and signing out no longer turns it off.

## Account, Teams and Security

- Fixed plugin and MCP server install links so a web page can no longer install anything on its own: Enconvo now shows what the link would install and where it comes from, and installs only after you click Install or Add.
- Added more than one Seat per account in Teams, so a Team admin can use − and + on any row, their own included, to let that account sign in on more Macs.
- Fixed Log In in Settings → Account and a connector's Sign in button so a browser that is already signed in asks which account to use, and the Signing in screen now has Cancel and Open browser again instead of waiting forever.
- Added Continue with Google back to signing in and creating an account from the iPhone and Android apps.
- Fixed the Continue with Google button on the sign-in and sign-up pages so it shows a spinner until Google opens, instead of looking like the tap did nothing.
