# Enconvo 2.5.14 Beta 4

Thanks for testing Enconvo 2.5.14 Beta 4. This build lets you pair a phone with its own camera, makes sure the first message of a new phone chat reaches your Mac, stops Claude Code and Codex asking for approval at Full access, adds Gemini 4 Hydrogen, and makes Recordings summaries resizable and selectable.

## Highlights

- **Pair with your phone's camera**: point the iPhone Camera, an Android camera or Google Lens at the pairing code and Enconvo opens to confirm.
- **Full access means full access**: new Claude Code and Codex chats start without approval prompts when Enconvo is at Full access.
- **Gemini 4 Hydrogen**: Google's fast new model for everyday coding and agent work.
- **Recordings**: drag to widen the Summary panel, and select and copy its text.

## Agents and Permissions

- Fixed Claude Code and Codex chats still asking for approval at Full access: with Enconvo's Permissions at Full access, new Claude Code and Codex chats started on this Mac begin in Bypass permissions and Full access (where Claude Code's settings allow Bypass), a Codex chat at Full access approves its subagents' commands, edits and permission requests and trusts new hooks without asking, and Claude Code at Bypass permissions no longer asks about protected folders or its subagents' calls.
- Fixed a Project's lead chat keeping the Permission mode its turn started in: switching the Project to Full access now takes effect on the next command of a run already going.
- Changed Approve for me to stop asking before commands that only set PATH for themselves, or that delete what they made under the temporary folder (such as a temporary git worktree), while deleting anything else still asks.
- Changed approval cards to say which setting made them ask, such as "Asked because this Project is on Approve for me."
- Fixed an Agent set to Auto answering a question about a problem in your own app, project or setup without its tools (and saying it had none): such questions, and every question in a Project chat about its work, now run as Agent, so it looks into your code, logs and data.

## Models

- Added Gemini 4 Hydrogen, Google's fast successor to Gemini 3.8 Flash for everyday coding and agent work: choose it in Enconvo Cloud, with your own Gemini API key (the free tier works too), or in Google Antigravity when your plan offers it. Its thinking levels are Low, Medium, High (default) and X-High, which thinks longest on hard multi-step tasks, also on iPhone and Android.

## iPhone and Android

- Added pairing with your phone's own camera: point the iPhone Camera, an Android camera or Google Lens at the pairing code in Settings › Connections and Enconvo opens and asks you to confirm the Mac; without the app, the link helps you install it and then pair, and scanning from the Enconvo app works as before.
- Fixed the first message of a new Mac chat started on iPhone or Android sometimes getting lost, leaving the chat with its title and nothing in it: the phone now checks the Mac received it and sends it again if it didn't, and a message the chat couldn't take goes back to the message box.
- Changed the phone apps' Home on a Mac: your active chats now show right above the composer (with the Mac's suggestions when nothing is running), a Screen button in the header opens Mac Screen, and the project name no longer gets cut off.
- Changed the phone apps' Speed and reasoning sheet to list the reasoning efforts above the speeds.
- Changed the Friends and Spaces headings in the phone apps' sidebar so tapping anywhere left of their buttons folds or opens the group, not just the name and its arrow.
- Fixed stat tiles in chat cutting off a long value such as "about 126K" on iPhone, Android and the Dynamic Island: the value now shrinks to fit its tile and wraps when it still doesn't, so its unit always shows.

## Recordings and Dictation

- Added an adjustable width for the Summary panel in Recordings: drag its left edge to widen it for long summaries, double-click the edge to go back to the default, and the width is kept for every recording.
- Fixed text in the Summary, Action items and Notes tabs of Recordings not being selectable: drag over any part of it to copy it with Command-C, the right-click menu or the selection toolbar.
- Fixed Dictation's meeting mute for Google Meet in other languages: the microphone is now muted in Meet in any of its languages, Russian and Ukrainian included, and when Meet's button can't be read you're told once to mute yourself there.
