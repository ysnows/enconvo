# Enconvo 2.5.6 Beta 8

Thanks for testing Enconvo 2.5.6 Beta 8, with a richer Knowledge Base,
more capable agents, and smoother voice conversations.

## Highlights

- **Ask AI about what you are reading**: chat with documents, books, and recordings, with citations that jump to the relevant passage or moment.
- **Agents can work together**: subagents handle independent tasks in parallel, with clear progress and support for your own project helpers.
- **GPT-6.1 Sol is available** through your API key, ChatGPT subscription, or Enconvo Cloud Plan.
- **More control over agent work**: choose permissions, follow a task checklist, undo file changes, edit earlier messages, and fork conversations.
- **Bring your Avatar into voice calls** from SmartBar or the Dynamic Island, with lip sync for spoken agent replies.
- **More services in reach** with new Connectors for automation, email, analytics, databases, and everyday work.

## Knowledge Base and Ask AI

- Added EPUB reading with a contents list, chapter navigation, adjustable text size, and remembered reading position.
- Changed Knowledge Base browsing to open inside Chat Window or Settings, with folders first, breadcrumbs, cover previews, sorting, and grid or list views.
- Added upload progress for each file, showing its reading and indexing status and keeping failures visible.
- Changed notes to open in an autosaving Markdown editor with source mode and word counts, and fixed the block menu when using a Chinese keyboard.
- Added text selection and copying in PDF previews.
- Added Ask AI to document previews, with clickable citations, selected-text questions, translation, page captures, model selection, and saved conversations for each item.
- Added reusable instructions for Ask AI answers, including your preferred language.
- Added Ask AI to recordings, live captions, and transcriptions, with citations that play the recording from the relevant moment.
- Changed saved web pages to open in your browser while keeping their saved preview available.

## Agents and Projects

- Added subagents, including a read-only explorer, your own Agents, and project-defined helpers, with progress cards and a Subagents group in the mention menu.
- Added a task checklist that updates as the agent works.
- Added permission choices and clearer approval requests across Chat Window, SmartBar, the app sidebar, and Dynamic Island.
- Fixed changing Permissions while an agent works so the new mode applies right away, including to a waiting approval and to its subagents.
- Added free-text answers and optional notes to agent questions, with reminders on your paired iPhone when a question or approval is waiting.
- Added Undo for agent-created and edited files, editing and resending earlier messages, and branching a conversation with Fork from here.
- Added the /compact command to summarize a long conversation and keep working.
- Added project skills and instructions from the project's parent folders, and fixed project and subagent file operations using the wrong working folder.
- Changed independent searches and lookups to run together, and made agents start answering sooner.
- Changed long-running tools and oversized results so they no longer hold up or overwhelm the conversation.
- Fixed subagent errors, interrupted work, repeated steps, and direct replies in subagent chats.
- Changed agent file editing to ask when a replacement is ambiguous, preserve replacement text, and create missing folders when needed.
- Changed agent hooks to support blocking or rewriting tool calls and continuing an agent or subagent before it finishes.
- Added product help to Mavis for Enconvo features, settings, permissions, and shortcuts.

## Models, Search, and Chat

- Added GPT-6.1 Sol with updated pricing and reasoning choices.
- Changed ChatGPT subscription model lists to discover available models automatically, with an offline fallback.
- Changed model pickers to use consistent provider ordering and remember copied providers, selected models, and reasoning settings correctly.
- Changed Search chats with date groups, highlighted excerpts, matching-message navigation, a wider-window preview, and more results as you scroll.
- Fixed chat search filtering, multi-word matches, and Chinese or Japanese excerpts.
- Fixed news searches and date filters so recent releases and events are easier to find.
- Changed Enconvo Cloud X Search to use Grok 4.7 by default, with faster searches.
- Fixed AI provider loading during extension updates and shortened retries for Claude requests that never begin responding.
- Changed Account settings to show cached plan information immediately and offer relevant plans or top-ups when Cloud points run out.
- Fixed sign-in recovery so a pending request can continue after you sign in again.
- Changed the points pill to show the prompt cache hit rate only on the Context tab, for the latest request, so the Usage tab no longer shows a second, conversation-wide rate.
- Fixed Control-B toggling the sidebar in the chat, Settings, and Knowledge Base windows on Mac, so it moves the cursor back in text fields again; Command-B still toggles the sidebar.

## Voice, Avatar, and Screen Doodle

- Added an Avatar toggle during voice calls without ending the call, plus lip sync for spoken agent replies.
- Changed Avatar controls with quick energy modes, looks, motions, and opacity choices, and removed message bars covering the character.
- Added screenshots to Dynamic Island Voice Command requests, with a setting to turn them off.
- Changed Voice Command replies to show spoken sentences in place with smoother transitions.
- Fixed voice-call control hit areas and errors when enabling the Avatar during a call.
- Added Save As for full-resolution Screen Doodle screenshots and drag-to-move for existing marks.
- Changed Screen Doodle selection with a clearer hint, dimming around the selected area, and single-click full-screen capture.
- Fixed auto-paste into browser editors and keyboard shortcuts being intercepted by a hidden SmartBar.

## Connections and Keep Awake

- Added Connectors for Zapier, Make, Resend, Prisma, ClickHouse, Shortcut, MotherDuck, Customer.io, Windsor.ai, and Superhuman Mail.
- Added Connectors for PayPal, Ahrefs, Similarweb, Apify, MailerLite, Omnisend, Replit, Datadog, Buffer, Cal.com, Cloudinary, and New Relic.
- Added a Tailscale plugin for checking devices, connections, and troubleshooting access.
- Added a dedicated Keep Awake page that works without signing in or pairing a phone, with battery support, a countdown, screen-on options, and optional lid-closed operation.
- Fixed Mobile Companion settings to explain connection and action failures clearly.

## iPhone Companion

These improvements also require the corresponding iPhone Companion update.

- Changed voice calls with compact controls, easier typing, a clearer character stage, and scrollable captions.
- Added quick access to pictures, files, and links delivered during a voice call.
- Changed model selection with provider tabs, search, and an Add key option.
- Added Permissions choices for agents in a Mac chat's menu, with a confirmation before switching to Full access.
- Fixed iPhone chats to reconnect safely without duplicate sends or replies and use clearer titles for messages containing links.
- Fixed inline code, bold text around Chinese or Japanese punctuation, and wide tables.
- Changed agent questions to stay usable while typing and on smaller screens.
- Removed the Answered on Mac note that stayed in a Mac chat after a question was answered.
- Changed chats so dragging the messages down puts the keyboard away right away.
- Changed sign-out to show progress and preserve paired Macs for your account.
