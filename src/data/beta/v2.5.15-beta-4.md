# Enconvo 2.5.15 Beta 4

Thanks for testing Enconvo 2.5.15 Beta 4. This build adds model fallback, picks up unfinished work after Enconvo restarts, shows the agent's Browser Use and Computer Use work in a Picture-in-Picture window, keeps the calls your agent answers in a Calls section with a phone notification for each, and gives Live Photo avatars a background setting and a choice of voice cloning provider.

## Highlights

- **Model fallback**: pick up to three backup models in Settings › AI Model, and a reply carries on with the next one when its model hits a limit or can't be reached.
- **Work picks up after a restart**: a chat stopped by an update, a quit or a crash goes on by itself once Enconvo is back.
- **Picture in Picture for Browser Use and Computer Use**: watch the agent work in a tab or window you can't see, and click to take over.
- **Calls the agent answers**: a phone notification for each one and a Calls section on Mac, iPhone and Android.
- **Wait For**: agents wait for a file, a log line, a process or a port in one step, without leaving shells behind.
- **Live Photo backgrounds**: transparent, a color, your own image or her photo, the same on the stage preview and in OBS.

## Chats and Agents

- Added Fallback in Settings › AI Model: pick up to three backup models, and when the model a chat uses reaches its usage limit, loses its sign-in or key, or can't be reached, the reply continues on the next backup, the chat says which model took over and why, and the original model is used again once it works.
- Added picking up work after Enconvo restarts: when an update, a quit or a crash stops a chat in the middle of a task, the chat goes on by itself once Enconvo is back, checks what it already did before doing the rest, and brings back the subagents it had running instead of starting new ones; a scheduled run, or a chat stopped a second time while picking up, says so in the chat instead.
- Added a Wait For tool for agents: an agent can wait for a file to appear, a line in a log, a process or command to finish, or a port or address to answer in one step, with no shell running, shown as one entry in the chat's background tasks, and it is told when the wait is met, fails or times out, so a job that crashes is reported right away instead of after a long wait.
- Fixed an agent waiting for long work on your computer leaving a sleeping shell behind for every check, which filled the chat's background tasks with "running" entries: an agent's command that only starts by sleeping is now turned back with how to wait in one call, and the agent waits with a single background check that wakes it when the work is done.
- Fixed agents getting stuck resending a broken tool call: when calls to the same tool keep failing on their input, the agent now gets the tool's parameters after the second failure, a clear note to change approach after the third, and the tool is paused after the fifth, so a bad call no longer loops a dozen times.
- Fixed agent shell commands in a folder whose Python environment has no pip of its own having every "pip" in them, including paths, file names and quoted text, changed to "uv pip"; pip now runs through uv there without touching the command.
- Fixed Full access asking before an agent deletes a folder whose name it builds from text and a command's output, such as a timestamped test folder, while deletes that could empty the home folder still ask.

## Picture in Picture

- Added a Picture-in-Picture window for Browser Use on Mac: while the agent works in a tab you can't see, a live view of the page shows in the corner of the screen, grows when you hover it, and takes you to the tab when you click it so you can take over, then Return to agent hands it back; choose Always, Only When I Am Needed or Off in Browser Use settings.
- Added the Picture-in-Picture window to Computer Use on Mac: while the agent works in an app window you can't see, including one it moved off screen, the window shows live in the corner, turns amber with what the agent needs when it asks for you, and takes you to the window when you click it; choose Always, Only When I Am Needed or Off in Computer Use settings.
- Added showing every waiting task at once in the Picture-in-Picture window on Mac: click +N more to stack up to three live views with the one that needs you nearest the corner, and Show less to fold them back.

## Calls

- Added a phone notification for every call the agent answers for you with Answer my calls: it says who called, what they want in one sentence and whether it's urgent, breaks through Focus and quiet hours when it is, and offers Call back and Open, which goes straight to the call.
- Added a Calls section on Mac, iPhone and Android that keeps the calls the agent answered apart from your other chats, marks the ones that are urgent, want a call back or are still unread, and lets you call back or mark a call done from the call itself.

## Chat Window and Dynamic Island

- Changed the Chat Window's Active chats list to show only chats that still need you, are running or have an unopened result: a finished chat you've already read no longer stays there, and the one you just opened from it stays until you open another chat or reopen the window.
- Added an Archive button to rows in the Chat Window's Active chats list, shown on hover for any chat that isn't running.
- Fixed a parallel chat an agent opens, or an archived chat that runs again, so it shows in the Chat Window sidebar with its running mark while it works instead of only once it finishes.
- Fixed picking another computer in the Chat Window looking frozen while its page loads: the main area now shows "Connecting to …" the moment you pick it, and its chat replaces that as soon as it is ready.
- Fixed the row of Agent cards on the Chat Window's new chat start page being out of reach with a mouse that has only a vertical wheel: the wheel now scrolls the row sideways, hovering the row shows an arrow at each end that has more cards, and an end fades out only while there is more past it.
- Fixed the Dynamic Island's Home on Mac showing one agent's icon on the Default Agent button and another agent's model beside it after the Default Agent changed in Settings or elsewhere: the empty Home now always runs the Default Agent the button shows, and the button dims with a dot when that agent can't run on your Mac, opening how to set it up.

## Live Photo Avatars

- Added a Background setting to the Live page of Live Photo avatars: choose Transparent, a color (green screen included), your own image, a blurred copy of her photo, or her original photo, for every cut-out avatar at once, and OBS gets exactly what the stage preview shows; it replaces the Cutout switch, and avatars saved with a framed backdrop keep their own photo and frame.
- Added a provider choice when cloning a voice for a Live Photo avatar: clone with ElevenLabs on Enconvo Cloud or your own API key, with clear prompts to sign in, add a key, use your own key or pick a ready-made voice when the month's clones are used up; closing the dialog while a voice is cloning asks first and cancels the clone, and your recorded or uploaded samples stay for next time.
- Fixed a Live Photo avatar's face freezing for a moment in the middle of a long answer while her voice went on: her voice now reaches her picture well before it plays, so her lips keep moving with it.
- Fixed recording a voice sample for a Live Photo Avatar always ending with "The recording was not saved.", so a voice can now be cloned from a recording made in place.
- Fixed the Live page of Live Photo avatars showing no stage preview in Portrait 9:16.
